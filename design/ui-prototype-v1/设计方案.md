# EdaKit 内嵌元件工作台：设计评审 V1

日期：2026-10-20。交付为独立 HTML 交互原型，未修改 `src`、主 exe、TCL 或运行配置。原型只供确认布局、信息层级及操作体验，不代表属性接口或真实 CAD 已全部接入。

## 建议方向

沿用 EdaKit 的深蓝标识与青绿色操作色，主体改为白色工程工作区。减少厚边框、整块大按钮及提示堆叠。信息以“先缩小范围，再比较器件，最后查看并放置”为主线。

整体分四区：左侧分类导航；顶部关键词与类目参数；中央表格；右侧固定器件详情与预览。参数可展开收起；正式版建议增加分类栏收起功能。表格独立滚动、表头固定，详情不随结果滚动。无需为了看封装滑到结果底部。

在宽屏保留分类侧栏和 340～390px 详情，1024px 时缩窄分类/详情、隐藏低优先级表格列。原型同时提供窄屏布局，便于检验收缩逻辑；正式产品优先保障 Capture 的桌面工作区，而不是追求手机功能。

## 搜索与分类：从关键词检索升级为参数查询

当前后端已调用上游 `param/group`，但主要只对外提供 Package。2026-10-20 再次对真实叶类核查，其他参数并非都没有，而是尚未映射和呈现在 EdaKit 中：

| 叶类 | 真实返回的部分键 | 建议首屏参数 |
|---|---|---|
| 贴片电阻 1199 | Resistance、Tolerance、Power(Watts)、Temperature Coefficient、Voltage Rating、Type | 阻值、封装、精度、功率、品牌 |
| 陶瓷电容 1142 | Capacitance、Tolerance、Voltage Rating、Temperature Coefficient、Pin Spacing | 容值、封装、精度、耐压、品牌 |
| 固定电感 1181 | Inductance、Current Rating、DC Resistance(DCR)、Current - Saturation(Isat)、Magnetic Core | 感值、封装、额定电流、DCR、品牌 |
| 单片机 941 | CPU Core、CPU Maximum Speed、Voltage - Supply、Interface、Program Storage Size、Number of I/O | 内核、封装、频率、工作电压、品牌 |

实际字段随类目变化，不能写死一张全局表。电容介质可能在 Temperature Coefficient 中表达；电感屏蔽属性不能仅凭界面名称认定有对应上游字段。正式版应显示上游真实存在且映射确定的参数；未匹配字段不伪造选项。

正式数据结构建议：`facets[] = {key, label, type, unit, values[], source}`。保留原始英文 key 与原始 option label 用于请求，中文仅用于显示；延续数值标准化，不能用中文展示名替换 API 参数键。封装、品牌、库存等系统条件与技术参数分别适配到实际请求字段。

实施规则：

1. 类目变化后读取该类目的参数 schema；上方默认显示 5 个常用参数，其余“更多参数”展开；允许用户固定常用项。
2. 正式多选：同属性内为“或”，不同属性之间为“且”。筛选弹层支持搜索选项和清除；大量阻值不能全塞进原生长下拉菜单。
3. 不默认自动查询商品。修改条件显示待应用提示，点击查询/Enter 提交整个快照，翻页和排序沿用已提交快照。
4. 切换类目清除不适用参数；跨类目时不能把阻值带进电容筛选。旧结果若保留，应明确其原类目和条件。
5. 联动选项应采用“本属性不限制自身、其他属性照常参与”的规则，防止选中 0603 后其他封装全消失。该规则必须用真实上游验证，不假定接口已原生支持；必要时只联动类目与关键词，明确告知范围。
6. 精确编号/型号和数值查询分开：保留 C 编号、型号路径；4.7K 结合电阻类解释为 Resistance 参数，不继续当普通文本。
7. 数值范围、上下限、单位和多选需要单独验证请求语义。上游有 isRange / standardUnitValue 等元数据，但不能仅据字段存在便宣称范围查询可用。
8. 缓存键包含类目、标准化参数、关键词及请求版本，避免旧结果污染新条件；给响应加序号，快速切换不串选项。
9. 库存、CAD/3D 有无只有在全量查询有可靠支持时才作为全局筛选。不能拿当前一页做筛选，却把分页总量当作筛选后的总量。

本原型主要验证单值下拉、动态类目参数、已选条件和明确查询流程。多选弹层、范围输入、自身排除式联动、在线数量、跨页 CAD 筛选尚未实现；这是下一阶段的真实接口开发范围。

## 等待 UI 设计

| 操作 | 区域反馈 | 超时/取消原则 |
|---|---|---|
| 类目与参数选项 | 对应下拉附近显示加载，保留已应用结果 | 失败可重试，不将失败显示为“没有选项” |
| 首次商品查询 | 表格行占位，查询按钮暂禁用，标明本次查询条件 | 条件可继续编辑；响应仅绑定提交快照 |
| 再次查询 | 正式版建议保留旧行淡化并标注“更新中” | 不把旧行误当作新条件结果 |
| 封装/符号/3D | 仅覆盖预览画布，型号参数仍可阅读 | 无模型、下载失败、渲染失败分别显示 |
| 长等待 | 小型任务条给出动作、等待秒数、已知阶段 | 未知总量不显示百分比；耗时提示阈值可调整 |
| 查询失败 | 结果区说明原因、保留筛选、一键重试 | 错误、无结果、取消三个状态区分 |
| 放置准备 | 按真实阶段显示读取数据、准备库、等待原理图 | 已向 Capture 投递后不能假装取消成功；必须读回执并提示切回原理图 |

原型“慢响应”8 秒返回，5 秒出现耗时提示，便于评审；正式超时继续结合现有约 25 秒 JSONP、45 秒图片策略，不能将演示计时当作接口性能承诺。原型取消仅取消本地演示回调；不代表正式后端线程或 Capture 请求已终止。

## 技术落地建议

| 方案 | 显示与交互 | 成本及边界 | 建议 |
|---|---|---|---|
| 沿用 Capture 当前 OpenURL 内核 | 简化样式也能实现侧栏、参数区、表格与详情工作区 | 继续 ES3/JSONP/PNG，使用现有布局技术；不直接复制原型 Grid、Flex、SVG、现代 JS | 首选，以最小集成风险分阶段落地 |
| 换成现代浏览器承载（例如 WebView2） | 更容易承载复杂多选、范围输入和现代渲染 | 尚未验证 Capture 中嵌入、焦点、菜单及原理图激活；还需安装/分发评估 | 单独验证可行性后再决定 |

本 HTML 原型采用现代浏览器、无框架、无 CDN、无外部请求，直接双击可运行。它不应未经适配就塞入 Capture；旧内核的兼容版应根据本稿重建布局并真机验证。当前真正的 PCB/3D PNG 管线与 PlaceNew 链路继续保留。

## 建议实施顺序

1. 先评审本稿布局、密度、参数摆放和等待状态。
2. 实现后端 facet schema、中文参数映射与通用参数请求；用电阻/电容/电感/单片机真实接口逐类验证，重点检查选项与结果一致。
3. 对现有内嵌页做兼容布局和等待状态改造，保留已验证放置链路。
4. 补齐多选、范围、品牌等已确认的请求语义；库存/CAD/3D 等未验证条件另列能力清单。
5. Capture 真机验收；再讨论是否值得改承载内核。

## 打开与评审步骤

直接打开本目录 `index.html`，或 PowerShell：

```powershell
Start-Process 'E:\outputs\edakit\design\ui-prototype-v1\index.html'
```

不需要停止现有服务或替换 exe，也不需要联网。

1. 观察宽屏和缩窄窗口时，筛选、列表、详情是否符合工作习惯。
2. 展开“更多参数”，改精度/封装，确认待应用提示，点击查询；单击器件看右侧详情。
3. 切换电容、电感、单片机，观察参数标题随类目变化。用电容 0.1uF + 0603 查询示例结果。
4. 在顶部“查询演示”切换正常、慢响应、失败、无结果；慢响应时可以取消，失败时可以重试。
5. 切换 PCB/符号/3D 示意、放大查看并按 Esc；点击放置只显示模拟提示，不发送请求。

反馈建议：布局是否接受；默认展示哪些参数；是否需要可收起分类栏；表格更紧凑还是更宽松；等待提示是否清楚；优先实施哪些真实筛选能力。

Browser 插件及其 skill 未列出，使用现有 Playwright + Edge。1600×1000、1024×700、390×844 均无横向页面溢出；类别切换、参数草稿、查询占位、精度过滤、慢响应取消、错误重试、空结果、单位等价、模型页签与大图 Esc 均通过，无页面/控制台错误。

设计检查维度：①深蓝/白/青绿配色与正式品牌一致；②分类、筛选、表格、详情四区稳定；③标题、标签、数值采用明确字号层级；④放置按钮缩为局部操作；⑤预览保留独立画布；⑥窄窗口减少低优先列而不撑破整页；⑦演示说明不与真实 Capture 状态混淆。截图为实际浏览器渲染，非生成图片。

### 评审时的具体检查与预期

1. 打开 `index.html` 后，默认是 4.7kΩ + 0603，显示 4 个示例器件；结果区与右侧预览分别保留位置。
2. 展开“更多参数”，将精度设为 ±1%。应先出现待应用提示，列表保持原结果；点击查询后显示占位行，约 1 秒后剩 3 个示例器件。
3. 将“查询演示”切换为“慢响应”，点击查询；5 秒后出现耗时提示。点击取消应恢复旧结果，查询按钮恢复可用。再选“查询失败”并查询，应显示保留条件及重试按钮；点击重试可恢复结果。
4. 切换“电容”，在关键词输入 `0.1uF`，封装选 `0603`，查询演示改回正常后点击查询，应得到 3 个 100nF 示例器件。类目切换前的结果标题仍描述旧结果，提交后才切换。
5. 选择器件，切换 PCB / 原理图 / 3D；点击放大查看可打开大图，Esc 关闭。3D 是示意；放置与数据手册按钮只演示反馈。
6. 缩小浏览器到约 1024×700；右侧应同时可见封装和缩放工具。展开更多参数时筛选区可独立滚动；不要求把全部参数及画布同时展开到最大。

无需停止现有 EdaKit 或替换任何文件。退出评审只需关闭原型浏览器标签页，无回滚步骤。反馈时请注明窗口尺寸、操作步骤、预期与实际效果，并附对应页面截图。

补充检查：本地 file:// 打开正常；1024×700 展开更多参数时预览及工具栏仍可见；切换分类待提交时的旧表头与旧结果保持一致。
