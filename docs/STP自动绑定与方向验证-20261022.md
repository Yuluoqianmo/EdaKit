# STP 自动绑定与方向一致性

2026-10-22。工作台“生成 PCB 封装”现在自动准备 STP 模型，把模型与安装方向写入原生 DRA / PSM。库设置新增独立的“STP / STEP 三维模型库目录”，首次默认 `D:/EdaKit/Libraries/STEP`。已有配置未设置该字段时，使用现有 PCB 库的同级 STEP 目录，保留原理图库及 PCB 库位置。

## 使用和验收

1. 保存工程，退出所有 Capture，再重新打开；已打开的 Allegro 也重启一次，以读取新的 steppath。
2. 打开商城 → 库设置，确认原理图库、PCB 库、STP 库和 Cadence 安装目录。STP 可单独选择目录，支持与 PCB 库分开保存。
3. 搜索 **C165948 / TYPE-C-31-M-12**，点击“生成 PCB 封装”。底部结果应包含“STP 已下载并与封装绑定”以及模型完整路径。再次点击应复用文件。
4. 打开“3D 模型”，点击“俯视对齐”，再切换“PCB 封装”：USB-C 的信号触点应在同一侧。拖动改变的是观察视角，不会改变封装内保存的安装方向。
5. 新放置该器件的原理图符号，再生成网表导入测试 PCB；在 Allegro 3D Canvas 中检查开口方向、触点侧和安装高度。已有原理图实例不会自动更换 PCBFootprint 属性；请重新放置，或按本次生成结果更新该属性后再导入。
6. 可继续测试 C168688 / C393939（USB-C 槽孔）、C2040（QFN）、C8734（QFP）、C23630（0603 电容）、C2686214（通孔电容）、C7171（极性及填充）。

本轮因修正原生坐标及增加模型身份，生成的封装名和配对符号名会改变。原有库文件、工程实例和旧 PCB 不会自动覆盖或改写。

## 实现依据

- 封装解析保留源画布 Y 向下；生成原生文件时，`footprint/coordinates.py` 一次性转换到右手坐标。同步转换焊盘及局部钻孔偏移、引脚位置/角度、自定义铜形、线、圆、矩形、圆弧方向、填充及内孔。PCB 预览保留源数据的俯视外观。
- 模型依据 SVGNODE 的旋转、轮廓中心和安装高度定位。模型 OBJ 与 STEP 使用同一局部坐标；旋转后，XY 包围盒中心对齐源轮廓，最低点按源 z 定位；负 z 保留。源 `c_origin` 可能过期，C23630 的源轮廓居中而 c_origin 偏移约 0.5 mm，因此优先采用轮廓。无轮廓时回退 c_origin。
- 预览和原生绑定共用 `threed/assembly.py` 的旋转/偏移。3D 俯视投影从原生 Y 向上转换到屏幕 Y 向下；不通过镜像实体来伪装对齐。
- 本机 Cadence 17.2 文档 `algroskill/06intedt.html` 的 axlStepSet、`07dbaccs.html` 的 axlStepGet 支持在 DRA 保存 STEP 主映射。先绑定，再保存并编译 PSM；回读模型名及全部旋转/偏移，误差上限 0.0002 mm。
- 17.2 S079 实测：刚从 mil 模板改为 mm 后，axlStepSet 的偏移仍按 mil 解释；1 mm 写入值会回读为 0.0254 mm。绑定时显式切换 mil 并换算偏移，完成后恢复毫米并回读，避免依赖该版本的单位行为。

## 缓存、异常与搜索路径

STP 按模型 UUID 保存为 `ek3d_<uuid>.stp`，附带 SHA256 收据及 OBJ 预览缓存。校验下载文件的 STEP 标识、结构段和结束标识。已修改或无收据的同名 STP 不覆盖；下载/校验失败时不发布本次封装，界面明确提示重试。上游没有模型时仍可生成 PCB，并明确显示未绑定 3D。

封装身份包含模型 UUID、源安装参数及坐标版本；相同二维几何但不同模型不会错误共享已绑定的 PSM。重复生成同时检查原生库和模型文件摘要；修改 STP 库目录后，会在新目录准备模型，封装通过模型文件名配合 steppath 查找。若同名已发布封装的实际模型或映射发生变化，阻止用新收据标记旧二进制。

环境配置只更新本工具标记块：padpath / psmpath 指向 PCB 库，steppath 指向 STP 库，保留用户其他搜索路径。CLI 普通导出的 STEP 也使用独立模型库；自动原生绑定由工作台生成流程完成，旧式 XML 映射不作为本轮原生绑定的验收依据。
