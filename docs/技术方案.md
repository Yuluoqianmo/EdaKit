# EdaKit 技术方案

## 架构

Capture Tcl 菜单启动携带宿主 PID 的 Python 服务，CEF 右侧面板通过 XHR/JSON 访问 HTTP API。服务追踪 Capture 宿主，最后宿主退出后停止；独立调试服务由调用方管理。页面兼容 Chrome45/ES3。frontend 是源文件，tools/build_web.py 生成部署资源，不删除其中任意一套。

HTTP/CLI 调用 services，配置在 config.py，缓存与预览任务有并发限制。放置队列支持会话定向、独占领取、收据与超时处理。符号 XML 按内容摘要生成稳定独立 OLB，保留已验证缓存，累积工程库有共享锁。Capture 原生 PlaceNew/PlacePartEx 跟随光标放置，返回 0 为失败。符号与封装功能名不同：配对以物理引脚编号为准。

## 原理图

原理图经过 normalize_capture_symbol 统一处理格点、比例及原生引脚显示；当前缓存修订 P10。属性写到符号属性范围，保证放置继承。修改生成器需要改变适用缓存身份，已有工程实例由用户重新放置或更新。

## PCB

EasyEDA 源数据转换为以封装原点为基准的毫米几何，再合并同号层焊盘。生成 SKILL 前校验符号/封装配对和可支持几何。独立后台进程使用私有升级模板，执行建焊盘、引脚、丝印/装配、PLACE_BOUND、保存及编译；原生编号/坐标核对通过后发布到配置库，索引登记完整几何摘要。未知形状拒绝生成，用户工程不作为后台构建载体。

Padstack 名和 PCB 名按规范及几何摘要计算；注册表文件冲突时保留已有文件并报错。首次默认库根 D:/EdaKit/Libraries；历史自定义设置保留。本机迁移由显式配置操作完成。

详细范围见 [PCB 方案](PCB封装生成方案.md)，最新验证见 [项目交接](项目交接.md)。
