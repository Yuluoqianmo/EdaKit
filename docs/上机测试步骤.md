## 0. 先让文件夹右键能直接开 PowerShell 7

Windows 10 自带的「在此处打开 PowerShell 窗口」打开的是 **5.1**，不是 7，所以单独加一个菜单项。

### 0.1 导入（推荐，一次搞定）

双击 `tools\open-pwsh7-here.reg` → 提示「是否确认添加」→ **是** → 「已成功添加到注册表」→ 确定。

它一个管理员权限都不要，因为写的是 `HKCU\Software\Classes`（只对你当前用户生效）。
加完两处右键菜单：

- **文件夹空白处右键** → 「在此处打开 PowerShell 7」
- **在文件夹图标上右键** → 「在此处打开 PowerShell 7」

### 0.2 先确认 pwsh 的路径对不对

`.reg` 里写死的是 `C:\Program Files\PowerShell\7\pwsh.exe`（你截图里那个 PowerShell 7 通常装在这儿）。

确认方法：随便开一个 PowerShell 7 窗口，敲：

```powershell
$PSHOME
```

打印出来应该是 `C:\Program Files\PowerShell\7`。如果不一样，用记事本打开 `.reg`，
把里面 **两处** `C:\\Program Files\\PowerShell\\7\\pwsh.exe` 改成你的实际路径（注意反斜杠要写双份），
保存后再双击导入。

### 0.3 验证

去任意一个文件夹（比如 `D:\`），在空白处右键 → 应该看到「在此处打开 PowerShell 7」。
点它，新窗口的提示符应该直接停在这个目录上，并且标题栏是 `PowerShell 7`。

### 0.4 不想要了怎么删

双击 `tools\remove-pwsh7-here.reg`，或者手工删注册表：

```powershell
Remove-Item 'HKCU:\Software\Classes\Directory\Background\shell\PowerShell7Here' -Recurse -Force
Remove-Item 'HKCU:\Software\Classes\Directory\shell\PowerShell7Here' -Recurse -Force
```

### 0.5 如果公司策略禁了导入 .reg

不用改注册表也能干活，只是每次要多敲一句。开 PowerShell 7 后直接：

```powershell
cd "C:\Users\32657\AppData\Local\Claude-3p\local-agent-mode-sessions\436c78be\00000000\9e697ef4\outputs\lcsc2cadence\dist"
```

后面所有命令都在这个目录里敲。

> 两个已知差异：① 没有交互放置命令 → 放置落到固定坐标（500,500 mil），落位后可能要手工挪；
> ② `NewDisplayProp` 不在 → 不影响，属性是写进符号 XML 的。**直接看 B2。**

### B2. 采集参考库的 XML 结构（R1，决定符号能不能被 Capture 吃下）

这一步的目的：`.olb` 是未公开的二进制，我们生成的 XML 用的是**推测的标签名**。
必须从你版本的 Capture 里捞一份「真的长什么样」回来，我照着改。

#### B2-1. 在 Capture 里建一个参考元件

1. `File → New → Library`，存成 **`D:\cadence\ref.olb`**（目录要先建好：`D:\cadence`）。
2. 在这个库里新建一个 Part，**越简单越好**：一个矩形本体 + 两个引脚（1、2，引脚名 VCC / GND）。
3. 保存。

> **先确认文件真的存在**：资源管理器打开 `D:\cadence`，应该能看到 `ref.olb`，
> 且大小不是 0。这是后面一切的前提。

#### B2-2. 转成 XML

在 Capture 命令窗口敲（路径按你自己的来）：

```tcl
XMATIC_OLB2XML "D:/cadence/ref.olb" "D:/cadence/ref.xml"
```

**注意**：这条命令成功时会回一个 `_xxxx_p_DboState` 之类的值 —— **但它不保证写出了文件**。
所以敲完之后，务必去资源管理器确认 `D:\cadence\ref.xml` 真的出现了、且不是 0 字节。

**如果没生成文件，用诊断脚本查。** 在命令窗口先设好两个变量，再 source：

```tcl
set lcsc_olb "D:/cadence/ref.olb"
set lcsc_xml "D:/cadence/ref.xml"
source "C:/Users/32657/AppData/Local/Claude-3p/local-agent-mode-sessions/436c78be/00000000/9e697ef4/outputs/lcsc2cadence/dist/diag_olb2xml.tcl"
```

它会逐项检查并告诉你卡在哪：

```
  [info] input  (.olb) : D:/cadence/ref.olb
  [info] output (.xml) : D:/cadence/ref.xml
  [ok  ] XMATIC_OLB2XML is defined
  [ok  ] input exists, size = 12345 bytes        <- 没有这行就是 .olb 路径不对
  [ok  ] output directory exists: D:/cadence     <- 没有就自动建
  running: XMATIC_OLB2XML {D:/cadence/ref.olb} {D:/cadence/ref.xml}
  returned: _d09a4367ac020000_p_DboState
  [ok  ] output written, size = 4567 bytes       <- 关键
```

**三种典型结果：**

| 诊断输出 | 含义 | 怎么办 |
|---|---|---|
| `[FAIL] input file does not exist` | `.olb` 不在那个路径 | 回 Capture 用 `File → Open → Library` 打开看看真实路径，或另存到 `D:\cadence\ref.olb` |
| `[FAIL] no output file` + `returned: _..._p_DboState` | 命令回了句状态但没写文件 | 按它下面提示的，试 `XMATIC_OLB2XML {D:/cadence/ref.olb} ref.xml`，看 `pwd` 目录里有没有 |

**如果失败**，Capture 会写回一个带阶段的错误，界面上能看到，形如
