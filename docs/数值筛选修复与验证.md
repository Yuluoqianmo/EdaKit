# 数值筛选修复与验证（2026-10-20）

## 根因与修复

真实上游复现：贴片电阻 1199 + 原始关键词 `4.7K` 仅返回 6 个商品、4 种封装（0805/1206/2010/2512），加 0603 后为 0。它是文本匹配，不是阻值筛选。封装接口本身并未截取当前页，错误来自两个请求共同使用了错误的搜索语义。

新增 `catalog/values.py`，由商品查询和封装选项共同调用：完整的阻值、容值、感值转换为标准数值标签，通过 `paramNameValueMap` 精确筛选，同时清除原文字关键词。选择电阻分类时 `4.7K`、`4K7`、`4700Ω` 统一为 `Resistance: [4.7kΩ]`；`0.1uF` 转为 `Capacitance: [100nF]`；`4700nH` 转为 `Inductance: [4.7uH]`。保留封装、分类、分页条件。

补充防护：明确单位但未选分类时补入对应叶类 ID，避免上游 405；零欧姆同时匹配 0Ω/0mΩ；区分 M（兆）与 m（毫）。C 编号、完整型号、纯数字（0603、104、4700）、带额外条件的文本维持字面搜索。没有分类的 `4.7K` 存在歧义，仍按文本查询；选择电阻分类或输入 `4.7kΩ` 即可。暂不解析 `4.7K 1%` 等多条件文本，不能将其宣称为精确数值查询。

不修改前端、TCL、放置链路或 Allegro 生成器。
