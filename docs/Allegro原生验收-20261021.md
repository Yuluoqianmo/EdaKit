## 已准备的输入

- `two_pin/candidate.il`：两个矩形 SMD 焊盘，物理编号 1、2，功能名 A、K，横向间距 1.8 mm，焊盘 0.8 × 0.9 mm。仅作为几何/API 验证件，不作为制造推荐封装。
- `C2040/candidate.il`：从真实离线样本重新生成，57 个物理引脚，包含 EP=57。
- 每个目录附 `pinmap.json`，生成前先执行正式的引脚配对校验。
- `--probe` 复制 Cadence 官方 `smdres.dra` 到隔离目录，执行只读 SKILL 启动探针，保存 `result.json` 和进程输出。

工具拒绝复用已有输出目录，进程使用独立 `ALLEGRO_PCBENV`，不修改用户 HOME、正式库或当前工程。超时只结束本工具启动的进程。启动探针通过也不代表封装构建通过。

示例（在项目根目录的源码 Python 环境执行，输出路径必须不存在）：

```powershell
python tools/diag/prepare_native_footprint.py E:/outputs/.edakit-ui-qa/native-next --probe --timeout 45
```
