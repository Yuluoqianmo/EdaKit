## 顶部裁切的处理

此前历史测试证实：添加空白文字、矩形不能改变初始取景；缩小后的视图未随库保存。历史记录中“OLB 或 Tcl 无法实现”的断言范围过大，本轮只能确认现有 XML 生成链路没有验证过可控制初始留白的字段，不能承诺源码已解决自动留白。

Cadence 17.2 本机官方帮助 `doc/cap_ref/Schematic_page_editor_command_reference.html` 说明：Zoom Out 可用于 schematic page 或 part，并给出 `I` / `O` 快捷键；`doc/cap_ref/window_descriptions.html` 说明 Ctrl 加滚轮缩放。注意 UI 命令与 Tcl 的适用范围不同：此前在零件编辑器运行 `ZoomOut` 返回 `Command Requires SchematicView`，不再建议该 Tcl 命令。
