# 查询栏排版与等待反馈：更新和验证（2026-10-20）

## 1. 关闭与替换

在 Capture 按两次 Esc，保存工程并完全退出 Capture，关闭旧商城服务。
在 PowerShell 按顺序执行，报错时停止并保留输出：

```powershell
Get-CimInstance Win32_Process -Filter "Name = 'edakit.exe'" |
    Where-Object { $_.ExecutablePath -eq 'E:\outputs\edakit\dist\edakit.exe' } |
    ForEach-Object { Stop-Process -Id $_.ProcessId -ErrorAction SilentlyContinue }

Set-Location -LiteralPath 'E:\outputs\edakit'
Copy-Item '.\dist\edakit.exe' '.\dist\edakit.before-query-feedback.exe' -Force
Copy-Item '.\dist\query-feedback\edakit.exe' '.\dist\edakit.exe' -Force
.\dist\edakit.exe selftest
```

预期 11 项全部 OK。无需构建、安装依赖或重新部署 TCL。重新打开 Capture、测试工程，通过 EdaKit → LCSC Mall 进入。

## 2. 先选条件，点击查询

1. 页面打开后应显示“先设置筛选条件，再点击查询”，不立即请求商品结果。
2. 选择“电阻 → 贴片电阻”，等待封装选项加载，再选择 0603。预期下级分类和封装选项联动，但结果区仍不刷新。
3. 点击“查询”，预期按钮显示“查询中…”，结果区有等待遮罩和已等待秒数，完成后展示 0603 结果。
4. 不改变分类，在关键词中输入具体型号，再点击查询。预期分类、关键词和封装组合生效，查询不会清空分类。没有匹配商品时显示空结果说明。
5. 按 Enter 与点击“查询”效果相同。

## 3. 草稿与当前结果

1. 查询成功后，将封装改为 0402，但先不点查询。
2. 预期旧结果保留，结果上方明确标注“筛选已修改，点击查询应用”。
3. 如果当前结果有下一页，点击下一页：预期沿用已经查询的 0603 条件，不能悄悄应用 0402。
4. 点击“查询”，才更新为 0402 结果，并清除未应用标记。
5. 点击“重置”：预期清空关键词、各级分类和封装，但不自动发起商品查询。已有结果仍按上方所标条件显示；重新设置条件并查询后更新。

## 4. 排版与表头

检查第一行“分类”的三个下拉框，第二行“关键词、封装、查询、重置”对齐，控件不重叠。缩小 Capture 窗口后重复检查，自动浏览器已验证 1440×900 与 1024×600。

每页设为 100 条并滚动左侧列表，预期表头仍固定、右侧详情可见。每页数量和翻页只作用于已查询条件。

## 5. 等待反馈

- 初次加载分类、切换分类或输入关键词：出现“正在加载…”，封装选项加载后显示数量。输入有短暂防抖，避免每个按键立即请求。
- 查询：按钮暂时禁用，结果区等待遮罩显示已等待秒数，完成后自动恢复。查询过程中仍可编辑条件；本次结果以点击时的条件为准，新改动等待下一次查询。
- 选择器件：详情、商品资料/手册和预览各有等待提示，加载完成后提示结束。
- 选择 C2040 的 3D 模型或打开大图：首次下载/生成时显示提示，完成后显示图像；快速旋转最终应显示最新视角。
- 点击数据手册：链接暂时显示“正在打开手册…”，避免重复打开。
- 点击“放置”：按钮暂时显示“准备中”，等待数据生成及 Capture 状态；就绪后提示切回原理图落位。

操作很快时，提示可能短暂闪过。耗时超过 8 秒时，提示增加“耗时较长，请稍候”；没有真实总进度的操作只显示等待动画和秒数，不显示百分比。

查询/资料请求等待上限约 25 秒，图像等待上限约 45 秒。失败后应显示原因并恢复可操作状态；图像失败或超时可点击“适应窗口”重试。放置准备或状态查询失败时，请先看原理图和服务日志确认请求状态，避免把仍在执行的请求重复提交。

## 6. 放置及手册回归

重置后输入 C2040 并查询，选择器件。检查符号、封装、3D 和数据手册仍正常。
用 C25804 和 C2040 分别点击“放置”，切回原理图，检查跟随光标、单击正常落位、引脚正常，按 Esc 退出。
