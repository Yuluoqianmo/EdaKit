# 分类、封装筛选、3D 与数据手册（2026-10-20）

## 对照商城后的修正

参照中文商城实际目录 https://www.szlcsc.com/catalog.html ：电容、电阻、连接器、二极管、电源管理、开发工具、存储器、单片机、接口芯片等分开组织，不再把整个无源或 IC 大类作为唯一入口。当前映射 37 个电子分支；部分中文站合并分类按国际站的实际查询范围标明名称。不是复制中文站 ID。

中文站和国际站分类 ID 不是同一套，例如中文站电阻 308、贴片电阻 439；当前查询接口对应 501、1199。使用 src/edakit/catalog/scope.py 显式映射，保留真实查询 ID 与子树，排除综合五金、工业耗材及办公分支。服务运行时仍从上游读取子分类，不把研究快照当永久商品目录。

原分类浏览调用 third/catalog，这是第三方供应商商品列表，部分描述、PDF 等为空。现在统一使用主商品查询 POST /ftps/wm/product/query/list，分类字段 catalogIdList，封装字段 encapValueList。实测 1199 下的 0603/0402 结果全部符合指定封装，RP2040 + LQFN 返回 1 条，RP2040 + 0603 返回 0 条。

封装选项来自 POST /ftps/wm/product/query/param/group 的 Package 数组，覆盖分类，不是当前 30/50/100 条列表。商品列表查询和筛选接口都要求叶分类 ID，父分类要展开为叶子；关键词搜索先通过 global 获得匹配的叶分类；精确 C 编号则从该编号商品本身取得封装选项。实测贴片电阻有 368 个具名封装选项（不把“-”当成封装类型），RP2040 有 LQFN-56(7x7)。选项缓存 10 分钟，最多 32 个查询上下文。上游列表最多展示 5000 条，结果多时应继续用分类和封装缩小范围。

列表的封装列允许换行，完整名称也保留在悬停提示和详情中。切换搜索或分类时重置封装条件；翻页保留条件。

接口字段参考了作者发布的 lcsc 0.1.1 源码（https://pypi.org/project/lcsc/），随后直接向商城服务验证；未引入该依赖或复制其实现。上述是商城网页使用的非公开接口，仍沿用项目原有重试与错误提示。

## 3D 显示取舍

Capture 原页签旧内核不支持现代 WebGL。继续保留已验证的页签与光标放置路径，使用真实 OBJ 模型，由本地服务以正交投影、深度缓冲和材质着色生成 PNG；无需新增依赖、修改注册表或切换浏览器内核。

新增“3D 模型”页签、左右旋转/俯仰按钮、鼠标拖动松开后更新视角、滚轮缩放、适应窗口、大图及 Esc 返回。3D PNG 上限 1024 像素，允许在页面放大；2D 仍保留 1024/2048/4096 分辨率。模型/解析/图片缓存都有容量上限。没有模型时禁用 3D 页签，模型下载失败提示加载失败，不用假模型替代。

实测 RP2040 的真实模型：2546 个顶点、5062 个面；1024px 深度渲染约 0.36 秒（不含首次网络下载）。初版三角面按深度排序仍有遮挡错误，已改为逐像素深度缓冲并重新截图验证。

## Datasheet

商品资料通过独立端点获取，不依赖有无 CAD。先按精确 C 编号查询商城，再读取对应中文商品页的公开 __NEXT_DATA__。核对 productRecord.productCode 完全相同后，补齐封装和 pdfFileDetailVO；只接受规格书类型，不把 RoHS 等证书当数据手册。中文页不可用时保留原商城链接，仍无资料则明确显示暂无数据手册。

RP2040 的国际站 PDF 地址在当前网络返回 403；中文商品页 https://item.szlcsc.com/2392.html 提供的原始 PDF https://atta.szlcsc.com/upload/public/pdf/source/20210621/C2040_96F425825606B7957D87DD32E2512CA9.pdf 已验证 200、application/pdf、%PDF 文件头。

点击“Datasheet 数据手册”才调用系统默认浏览器打开同一器件的手册，避免旧内核缺少 PDF 插件。不会自动打开外部商城。链接只允许 http/https，打开前按 C 编号解析；切换器件使用请求序号防止旧手册串入。商品资料缓存 10 分钟，最多 128 条。

## 验证边界

自动浏览器使用现有 Playwright + Edge（当前会话未列出 Browser 插件），列表为隔离的模拟数据，分类、封装选项、RP2040 几何/模型来自实际上游。检查 1440×900、1024×600：分类选择、368 个封装选项、封装条件请求、长名称换行、真实 3D 图片、旋转/拖动/缩放/大图/Esc、无模型/无手册状态、快速切换响应保护、手册点击。手册打开系统调用在浏览器 QA 中拦截，在单元测试中校验对应 URL；实际 PDF 地址另外联网验证。

页面身份、有效内容、无错误覆盖层、应用控制台和交互检查通过。测试环境屏蔽了无关 favicon 请求。Capture 旧内核及系统 PDF 窗口的实际行为仍需按本轮验证步骤上机确认。Capture TCL / PlaceNew 与 Allegro 生成代码保持不变。
