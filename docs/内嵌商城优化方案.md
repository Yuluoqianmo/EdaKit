# 内嵌商城优化方案（2026-10-20）

## 目标与取舍

| 方案 | 效果与约束 | 本轮决定 |
|---|---|---|
| 继续 OpenURL 页签，服务端生成 PNG | 沿用已验证的页签/切回原理图流程；无需浏览器 SVG/Canvas，布局需兼容旧内核 | 采用 |
| 切换 Capture 自带 CEF | 可使用现代 CSS/SVG；历史实验中视图可创建，但子资源加载未解决，也未验证窗口激活的回归 | 暂不切换 |
| IE7 VML 绘制 | 可画矢量图，但需要再维护一套几何/文字渲染，并依赖已废弃的 VML 行为 | 不采用 |
| 强制提升 IE 文档模式或修改注册表 | 可能获得更多标准支持，但会影响宿主与其他内嵌页面；不同安装行为不确定 | 不采用 |
| 外部浏览器独立商城 | 用户要求取消 | 删除独立页面、浏览器入口和自动外部浏览器回退 |

PNG 引擎采用 resvg_py 0.5.0，复用现有 SVG 几何，1024/2048/4096 像素分级请求；按 SVG 内容和尺寸缓存，最多 24 张。请求尺寸只允许 512/1024/2048/4096，防止误请求超大图片。开发构建最低 Python 3.10；单文件 exe 已包含原生渲染库，使用者无需安装。

依据：
- resvg_py 官方 API：https://resvg-py.readthedocs.io/en/latest/api.html
- Windows 预编译包与 Python 版本：https://resvg-py.readthedocs.io/en/latest/installation.html
- 微软 VML 说明（已废弃）：https://learn.microsoft.com/en-us/windows/win32/vml/frequently-asked-questions-about-vml
- 本机 Capture 旧内核与 CEF 的既有实验：历史验证记录 U 节、交接文档 CEF 未解决项。

## 显示与交互

- 顶部搜索与中文三级分类固定；保留上游分类 ID，不改变分类查询语义。上游本次返回 53 个一级分类、1,208 个总节点，仅提供英文名。
- 常用电子分类使用人工词条，其他类别使用本地技术词汇组合；保留 ADC、MOSFET 等技术缩写，原始英文放在分类项提示中，未来新增未知词保留原文，避免猜错分类。
- 左侧结果表滚动，右侧详情独立固定；详情较长时仅详情信息区滚动。每页 30/50/100 条，型号/描述过长省略，悬停看完整内容。
- 右侧默认 PCB 封装，支持原理图符号切换；小封装充分利用视图，密集焊盘编号缩小，避免默认视图文字相互覆盖。
- 50%～800% 相对适应窗口缩放，按钮与滚轮均可操作；鼠标拖动平移；双击/按钮进入大图；Esc 关闭大图。
- 搜索与详情请求使用序号防止旧响应覆盖新选择；JSONP 请求有超时，加载失败提供提示。
- 跟随光标按钮继续调用已验证的队列与 PlaceNew 链路；本轮不改符号库生成和原生放置实现。

## 浏览器验证范围

使用 Playwright + 本机 Edge。当前没有独立 Browser 插件。验证服务与用户运行数据隔离；搜索结果为模拟数据，分类来自实测上游快照，符号/封装来自真实 C2040/C25804/C2337 样例。

已检查 1440×900、1024×600 两种桌面窗口；50/100 条搜索结果、固定详情、三级中文分类、默认封装、高清放大、拖动、Esc 关闭、搜索空结果、快速切换元件的旧响应保护。页面有内容、无框架错误覆盖层，无相关 JS 错误或控制台警告。以上不等同于 Capture IE7 文档模式的真机验证，需按验证步骤回归 PNG、样式、滚轮、拖动和放置。

本轮不扩展封装生成、3D 或 Allegro 功能。
