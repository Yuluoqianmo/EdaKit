## 关键结论

界面需要同时表达设计事实、制造选择、订单输入。板厚和铜厚有设计读取值，也有最终制造要求，必须分别保存。不能把所有字段做成自由输入，也不能把所有工艺都标记成“无法读取”。应先查PCB明确的制造属性；没有明确属性时才等待选择。不能将显示配色、默认叠层、走线阻抗目标当成已确认的制造要求。

Gerber图形不承载所有板材、厚度、颜色和表面处理需求。官网有默认工艺设置入口，不能仅凭页面出现了值就认定该值来自上传PCB。本次未上传文件，因此没有验证官网上传后的自动识别字段清单；本插件仍应独立从Allegro快照获取可验证信息。

## 用户模板30字段的处理建议

保持用户原有PCB说明/钢网工作簿及布局，窗口可以拆分子控件，最终组合写回原单元格。

| 工作表/字段 | 数据来源与窗口处理 |
| --- | --- |
| PCB说明/型号 | 当前PCB文件名带入，可修改 |
| 板子数量 | 订单输入；数量档位提供便捷选项，同时说明是单片还是拼板大片，不能从器件数量推断 |
| PCB尺寸 | 板框几何读取；显示mm，区分单板与已拼板整体尺寸，不自动取整成采购名义尺寸 |
| 是否加急 | 订单选择；实际交期依层数、工艺、数量联动，不承诺官网实时交期 |
| PCB层数 | 电气叠层读取，核对导出Gerber层数；异常时明确提示 |
| 制图软件 | 当前导出工具带入 |
| 切边层 | 从实际Artwork参数确定板框输出层/文件，不能仅凭存在BOARD GEOMETRY层猜测已导出 |
| 层序 | 从叠层读取，自上而下；核对交付文件与层名对应 |
| 板材 | PCB介质材料作为依据；另选类别、品牌/型号/TG，组合回填，FR-4不等于指定TG |
| 厚度 | 设计叠层厚度显示为参考；成品板厚按当前板种/层数的规格选择。无匹配时待确认，不能四舍五入到最近档 |
| 铜箔厚度 | 设计各层厚度为参考；分别选择外层/内层成品铜厚，合并写回。不要把30.48μm直接换成1oz订单要求 |
| 最小线宽/线距(mil) | 从铜图形分析实际线宽和不同网络间距；另显示设计规则下限，二者不可混写。当前版本尚未接入 |
| 最小孔径(mm) | 实际孔统计；分别区分过孔、插件PTH、NPTH、盲埋孔、槽孔。用于建议能力档位，但不改变孔数据 |
| 表面处理 | 先查明确制造属性，没有时从可用工艺选择；层数/板厚改变后重新校验 |
| 阻焊要求 | 拆成颜色、过孔处理、补充要求；检查Gerber开窗与选择一致，混合开窗按文件描述，不能硬归成全板单一值 |
| 丝印要求 | 拆成颜色、顶/底面与文字工艺；顶底丝印内容可从图层读，实际油墨颜色需明确属性或用户选择 |
| 金手指 | 明确区分是否存在金手指、是否斜边及其他镀层要求。识别不明确时待确认，不能用器件名字猜测 |
| 阻抗控制 | 读取已明确的阻抗目标/网络作为依据；选择是否管控、叠构和公差，必要时附阻抗表，存在高速网络不等于要求工厂阻抗测试 |
| 设计人员电话 | 读取已保存的用户输入；不从无关工程复用 |
| 其他 | 自由备注，补充模板没有单列的要求；不塞入未经确认的默认采购条款 |
| 钢网/型号 | 当前PCB文件名带入，可修改 |
| PCB尺寸 | 共用同一次板框读取 |
| 钢网尺寸 | 厂家钢网规格选择；受有效开口区、设备及拼板影响，不能只凭PCB长宽自动定规格 |
| 制作要求 | 保留用户模板四选项；依据顶底Paste是否有有效开口提供建议，不能从器件贴装面直接断定 |
| 数量 | 订单输入，不跟随PCB数量自动等量 |
| 钢网用途 | 保留模板锡膏网/红胶网选择 |
| MARK点 | 保留模板需要/不需要；读取到MARK图形不等于已确认钢网MARK制作方式 |
| 抛光工艺 | 保留模板选项；未核实当前钢网官网全部可选能力，不宣称与今天官网完全一致 |
| 工程处理要求 | 保留模板选项，用户明确选择 |
| 打印钢网型号（字符）到钢片上 | 保留模板需要/不需要 |

## 当前实现缺口和开发顺序

1. 首先分离设计读取值和已确认制造值。当前board_metadata把厚度和各层铜厚直接映射到模板制造字段，窗口会自动填入；这需要修正。已保存的人工设置继续保留，来源不明的旧自动值应迁移成待确认参考。
2. 给工艺参数增加有适用条件的选择器；无数据和未确认不能静默变成官网常用默认值。支持原来已保存的特殊要求，不能以不在当前标准列表中为由丢弃。
3. 将复合字段拆分显示，合并回原Excel单元格：铜厚、阻焊、丝印、阻抗。保持模板文件和样式不变。
4. 补充切边层、孔分类、有效Paste面和明确制造属性读取；线宽/线距需准确的几何或Cadence分析接口，不能只取默认规则充当实测。填孔、金手指等无法确证时显示待确认。
5. 校验说明与实际交付Gerber：层数/顺序、板框、过孔阻焊、钻孔与槽孔。仅更改加工说明不会修改Gerber，存在冲突时不能声称已完成工艺转换。
6. 测试重点是条件切换、旧值保留与冲突提示：2层转6层后喷锡失效；内层铜厚只在多层适用；0.1mm孔的工艺限制；手工规格不能被后台读取覆盖；混合开窗不会误写成全板盖油；板厚和铜厚不自动取最近规格。

## 后续实现补充（测试4）

再次实际打开官网，选择4层FR-4、10×10cm、5片，确认板厚可选0.6/0.8/1.0/1.2/1.6/2.0/2.5/3.0mm（0.4禁用），外层铜厚1/2oz、内层0.5/1/2oz。4层过孔盖油禁用，可选开窗、塞油、树脂+盖帽、铜浆+盖帽。上述选项已补入参考配置。

测试4实现制造选择与设计参考分离、内外铜厚/阻焊/丝印/阻抗等组合控件、层数/板材类别/板厚联动、旧自动值迁移和旧手工文本保留。2/4/6层FR-4板厚使用已核对列表，其他层数或板种不套用这些板厚选项，允许录入定制要求。页面选项是参考范围，不代表已实时核价确认任意组合可生产。绿色阻焊以外的字符颜色组合尚未逐一核实，窗口有提示。

改进未覆盖全部计划项：尚无实际最小线宽/线距计算、Artwork层与板框输出对应检查、Gerber过孔开窗几何一致性检查和完整盲埋孔/槽孔分类。元数据增加了实际圆孔的VIA/PTH/NPTH分类提示，调用-S请求阻焊与锡膏层；本机样板的原生IPC映射仍未导出这些图形，因此明确提示不可推断钢网面或过孔开窗，而不沿用未使用焊盘定义来猜测。
