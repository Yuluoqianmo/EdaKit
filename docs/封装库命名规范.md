# 封装库命名规范 v2

2026-10-21。参考用户提供的《PCB封装命名规范》V1.0（正文署名国仪量子技术有限公司，2020 年），采用类别、脚数、间距、尺寸及 EP 标识的思路。原 PDF 不随仓库分发。

| 对象 | 格式 / 示例 |
| --- | --- |
| Capture 内部零件名 | `EK_<CID>_S_<符号摘要前8位>_P10` |
| PCB 库名 / PCB Footprint | `<通用类别标签>_<几何摘要前10位>` |
| 电阻、电容、电感 | `R0603_<摘要>`、`C0402_<摘要>`、`L0603_<摘要>` |
| QFN | `QFN57_0D4_7X7_EP_<摘要>` |
| 未识别类别 | `<位号类别><物理脚数>_<摘要>`，例如 `U8_<摘要>` |
| Padstack | `EK_<标准化焊盘摘要前20位>` |
| 累积原理图库 | `<设置的原理图库目录>/EdaKit.olb` |

类别标签最多 20 字符，完整 PCB 名最多 31 字符；仅用 ASCII 字母、数字、下划线，小数点以 D 表示。发布文件名统一小写，逻辑名称保留可读大写。

## 类别标签

- 标准被动件识别 R/RES、C/CAP、L/IND 后的四位尺寸码，类别沿用原理图位号。
- QFN/LQFN 统一 QFN；SOP/SSOP/TSSOP/MSOP/TSOP/PSOP/SOIC 统一 SOP；QFP/LQFP/TQFP/PQFP 统一 QFP。
- 脚数采用实际物理编号总数，包括暴露焊盘 EP。C2040 原始名称写 56，但有编号 57 的 EP，故命名 QFN57…EP，配对仍保留 1～57；不得为符合名称而重编号。
- SOT、SC、TO 保留明确的标准型号，例如 `SOT23_5_<摘要>`。
- 仅从源封装显式 P、L、W 字段读取间距和尺寸，不以焊盘跨度冒充器件本体尺寸，不猜高度。尺寸标签顺序为 W×L，遵循参考文档的宽度在前。未知参数省略。
- 可读标签是分类提示；复用还需完整几何摘要相同。不同标准标签、不同位号前缀保守分开，避免误合并不同器件族或 R*/C*/L* 模板。

## 几何身份与复用

PCB 不再包含 CID、厂家型号、阻容值、源 UUID、原始记录文本、画布原点或 3D 模型名。同类、同几何的不同料号可复用一个原生封装；Capture 符号仍按料号保存自身属性。

摘要包含：命名/几何格式版本 2、规范类别标签、规范化位号前缀、每脚编号/位置/角度、各焊盘层/形状/尺寸/钻孔/金属化、线条及线宽、圆及线宽、填充区域和不支持图元的身份。集合按内容排序，浮点数据按实际输出的 0.0001 mm 精度归一。生成器也先统一精度再计算派生边界。

标准 RECT/CIRCLE/OBLONG 焊盘按宽高生成，源记录中附带的绝对角点不参与其身份；不支持的多边形形状仍保留多边形身份并拒绝不安全转换。相同标准焊盘跨位置、跨引脚、跨器件共用定义。

保留完整 SHA256 和原生文件 SHA256。短摘要同名而完整摘要不同即拒绝发布；无法归属或被修改的同名文件不覆盖。缓存命中前仍验证当前器件原理图/PCB 编号、数量及可用的独立名称映射，然后校验 DRA、PSM、PAD、清单版本及文件哈希。

## 配对及升级

Capture 的 `PCB Footprint`、`PCBFootprint` 与 Allegro 库名来自同一函数。非 Power 功能名消歧沿用既有规则，物理编号原样保留。源数据缺少独立 PCB 功能名时，只能证明编号映射，不能宣称完成独立功能名验证。

原理图引脚几何与显示规则沿用 P9，PCB 身份改版会改变对应符号摘要。旧实例及旧库文件不自动迁移/删除；更新后应重新放置测试器件，检查其新 PCB Footprint 后再生成网表。新版本不会复用旧 v1 注册表封装。
