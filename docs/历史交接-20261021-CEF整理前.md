## 6. 已打通的关键链路，不要退回旧实验

### 原生光标放置

```text
capGetMostRecentSchFrameID
→ DboTclHelper_sGetConstCharPtr
→ ui::SchematicActivate
→ 检查原理图活动、可编辑
→ UnSelectAll / ZoomRedraw
→ PlaceNew lib package 0
```

`PlacePartEx` 曾正常返回 armed 但光标没有器件，已停止自动选择。Place Part 面板路径曾产生散引脚，不是当前方案。无需再按旧交接试“PlacePart 后选中 Move”。

- `armed:` 仅说明原生命令调用没有抛 Tcl 异常，不证明已单击落位或几何正确。
- 商城活动时请求可以等待原理图；切回后执行并更新回执。不能丢失请求的模式、坐标、seq 或回执路径。
- 原生报错返回失败，不偷偷固定坐标插入。`slot` 是显式保留的旧模式；商城默认 `force_cursor=1`。
- TCL 需保持 ASCII（中文用转义）；库写入返回值不可信，应检查文件并回读。写存在的 OLB 前先备份挪走，规范化步骤保留。

### 商城与分类

- 主商品接口：`POST https://wmsc.lcsc.com/ftps/wm/product/query/list`，分类 `catalogIdList`，封装 `encapValueList`。
- 封装选项：`POST /ftps/wm/product/query/param/group` 的 `Package`，覆盖分类，不取当前页去重冒充完整选项。
- 新页面走 `/api/es/facets`，由参数接口取得 `paramNameValueMap`、`Package`、`Manufacturer`。商品接口对应 `paramNameValueMap`、`encapValueList`、`brandIdList`；HTTP 层用重复 `param.<原始字段>`、`package`、`brand` 参数传递多选。
- 属性选项范围固定为分类+关键词，缓存 600 秒/32 个上下文，不随其他已选属性收缩。页面已说明此边界，不能宣称全部条件级联计数或任意组合均有商品。旧 packages 端点仍兼容保留。
- 商品查询和封装选项均需叶分类 ID；`server/app.py::_leaf_ids` 展开一级/二级分支。直接提交父 ID 会得到空结果。
- `third/catalog` 是第三方供应商列表，不能替代主分类查询。
- 中文站与 wmsc ID 不同：例如中文电阻 308 / 贴片电阻 439，对应当前 wmsc 分支 501 / 1199。不要混用。
- 搜索选项通过匹配叶类获取；精确 C 编号直接取得该商品封装。368 种封装等数量是当日快照，不是固定业务常量。
- 上游非公开接口存在变化风险；当前列表返回总量最多 5000，需通过分类和封装收窄范围。

### 查询与等待反馈

- `draft()` 读取尚未提交的控件，`state.chosen` 保存草稿多选；`state.applied` 独立保存上次成功查询条件，`state.loading/failed` 保存正在查询/失败快照。分类或关键词更换清空参数并重新加载选项；参数修改和重置不发商品查询。
- “查询”/Enter 提交组合条件；分页保留完整 applied 快照。结果区显示条件与未应用修改；查询中仅遮住结果，原详情保留可用，成功后再重置详情。失败/取消保留此前成功状态，迟到响应通过序号隔离。
- 结果区骨架、底部任务、真实秒数、5 秒任务提示、8 秒耗时说明覆盖查询、参数、详情、图像、手册和放置。取消只停止页面等待/更新，不保证已发出的上游请求被终止。
