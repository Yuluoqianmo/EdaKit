## 改了什么

1. 深色标题、浅色工作区、统一控件与紧凑“放置”按钮；分类侧栏可收起，小窗口自动收起。结果与详情独立，固定表头，缩短窗口时压缩筛选和详情区域，保留预览。
2. 保留三级中文电子分类，根据分类和关键词读取真实可用属性。常用属性先展示，“更多参数”展开其余属性。支持阻值、容值、感值、精度、功率、耐压、温度特性、品牌等，具体取决于上游为该类目提供的字段。
3. 每个属性可搜索并多选，同属性多选为“或”、不同属性为“且”。品牌使用真实品牌 ID；封装和技术参数一并传到商品接口，翻页保留完整条件。已选条件可逐项移除。
4. 选好条件后点击“查询”或 Enter 才刷新结果。草稿和已提交条件分开；修改后未查询时有提示，翻页仍使用上次成功查询的条件。更换分类或关键词会清空旧参数，避免跨类目错误沿用。
5. 统一等待状态：底部任务状态、真实等待秒数、结果区骨架占位；超过 5 秒增加任务提示，超过 8 秒说明耗时较长。没有虚构百分比。支持取消查询、错误重试，迟到响应不会覆盖新结果，按钮防重复提交。
6. 保留真实二维、3D、数据手册和光标放置。TCL、PlaceNew、Allegro 相关源文件与本轮备份一致，无需重新 deploy。

边界说明：参数选项范围是“分类 + 关键词”，不随其他已选参数进一步缩减，也不表示当前组合一定有商品。此范围在页面明确标注；选项来自上游参数接口，未从当前页凑数。字段值保留上游单位和名称，常见字段标题已翻译，未识别字段保留原名。尚不提供自定义数值区间。多选面板一次显示最多 200 个匹配项，搜索仍覆盖完整选项集合，数量提示会提醒缩小关键词；每个属性最多选 50 项。

`4.7K` 结合电阻分类仍按精确 4.7kΩ 查询；`4K7`、`4700Ω` 等价。电容和电感的等价单位修复已包含在本包。关键词数值与所选数值矛盾时，明确报错并要求清除冲突条件，不会静默替换。

“取消查询”停止本页面等待与结果更新，已经发出的后端网络请求可能继续完成。网络请求约 25 秒、图像约 45 秒超时。放置已提交后，请先看原理图与提示确认状态，避免重复落位。

```powershell

```

预期：哈希等于本文 SHA256；11 项均为 `[OK]`，最后显示自检全部通过。不需要安装 Python、不需要重打包、不需要 deploy TCL。

3. 重新打开 Capture，打开测试工程及原理图页，通过 **EdaKit → LCSC Mall** 重新进入。标题应显示“EdaKit 元件工作台”，能看到查询、重置、分类、参数和左右结果/详情区。旧页面只刷新可能仍使用旧服务，需重新打开。
4. 如果仍显示旧版，保存退出 Capture 后，只停止主路径的服务，再重新打开 Capture：


## 二、布局与参数筛选

1. 最大化内嵌页，点击左侧“电阻”，选择“贴片电阻”，输入 `4.7K`。等“正在读取分类参数与封装”结束。应看到阻值、封装、精度、功率、品牌等；有 0603，而非只有原先 4 种封装。此时结果不应自动查询。
2. 点击封装，在面板搜索 `0603`，勾选 0603，关闭面板；在精度中勾选 `±1%`，点击“查询”。应返回商品；选中行的封装为 0603，阻值为 4.7kΩ、精度为 ±1%。手工核对前几行的描述/详情，不按固定库存数量验收。
3. 再勾选 `±5%`，此时应提示“有修改，查询后应用”。点击查询，结果允许 ±1% 或 ±5%，仍应满足 0603 和 4.7kΩ。品牌也可搜索并多选，查询后核对实际厂家。
4. 点击“更多参数”，选择一个上游提供的功率或温度相关属性，再查询；确认已选标签出现，结果符合条件。少量条件的组合可能为零，此时应显示空结果而非永久加载。
5. 有多页结果时，修改一个参数但暂不查询，再点下一页。结果区应提示尚未应用，翻页使用旧条件。重新点击查询才提交新条件并回到第一页。
6. 清空精度标签或“清空参数”，应清除选择且等待查询；“重置”清空分类、关键词和参数，也不会自动请求商品。更换分类或关键词时旧参数会清空，需重新选择。
7. 改成电容的陶瓷电容分类，输入 `100nF`，等待参数后选择 0603、额定电压 50V，再查询；结果应满足这三个条件。改用 `0.1uF`、重新选同样参数查询，语义应一致。
8. 电感分类测试 `4.7uH` 和 `4700nH`；重置后测试 `C2040` 或 `RP2040`。参数应随器件范围切换，不残留电阻属性。带歧义的无单位缩写请结合分类使用。

## 三、滚动、预览和小窗口

1. 选中一行后滚动结果列表。表头保持固定，右侧器件不被挤到页面底部，选中行有浅色强调。
2. 将 Capture 内嵌区域缩小至约 1024×700，再到约 1024×600；分类侧栏自动收起，仍能操作查询、参数、列表和预览。小窗口展开“更多参数”时在参数区内滚动，不会把预览挤出页面；查询等待时取消按钮也应完整可见。若字体缩放不同导致重叠，请记录 Windows 显示缩放及实际窗口截图。
3. 单击 0603 电阻，测试 PCB 封装与原理图符号，滚轮缩放、拖动、适应窗口、大图查看及 Esc 返回。
4. 查询 C2040，打开“3D 模型”，测试左右旋转、俯仰、缩放、大图。使用真实模型；无模型的器件应禁用相应页签，不显示虚构替代模型。
5. 点击“数据手册”，应由默认浏览器打开所选器件对应资料；连续点击只提交一次。打开新器件后不能残留上一器件资料或预览。

## 四、等待、取消和失败恢复

1. 发起查询，观察按钮“查询中”、结果骨架和底部任务/秒数。网速快时可能很快结束，不能因此判断等待功能失效。
2. 网络较慢时，超过 5 秒出现任务提示，超过 8 秒显示耗时较长；提示应说明正在查询/读取参数/加载模型等具体任务。
3. 查询尚未结束时点“取消本次查询”。按钮恢复可用，结果恢复此前状态；迟到响应不能覆盖画面。更改条件再次查询，结果应属于新条件。
4. 如果自然出现网络失败，应显示可理解的错误、保留条件并提供重试；参数加载失败则有“重新加载参数”。不必刻意断开公司网络来制造失败，自动化已单独覆盖慢响应、取消、迟到、空结果与错误恢复。
