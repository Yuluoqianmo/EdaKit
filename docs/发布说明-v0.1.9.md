# EdaKit v0.1.9

正式版本号为 0.1.9，适用于 Windows 64 位，主要验证环境为 Cadence 17.2。

## 本版内容

- Allegro 生产交付入口，按需生成 Gerber、钻孔/槽铣、坐标 Excel、加工说明 Excel 和交互式 iBOM。
- 默认复用 PCB 所在目录的 Output files 文件夹；导出进度、制造错误检查与同名文件覆盖确认。
- 加工说明及插件表单移除“设计人员电话”和“其他”，导出不再保留这两行。
- BOM 与坐标使用封面和数据表两张工作表，保留模板富文本样式及标识；清除示例物料、旧人员日期和外部工作簿链接。
- 旧单页 BOM 模板自动采用新版带封面布局；先前丢失富文本的封面自动恢复。
- 坐标增加器件类型、值、公差及封装，沿用已核对的毫米 XY、原始旋转角度及顶底面规则。
- Capture 和 Allegro 均可填写封面信息。坐标日期默认使用本机当天；编制等信息按工程保存。
- 坐标封面表单位于坐标输出卡片下方，默认折叠，展开后为紧凑五行布局。

独立原理图 PDF 功能尚未实现，本版不包含该功能。Linux 安装和 Cadence 集成未进行整体实机验收。

## 验证范围

- 全量回归：1000 项通过、2 项跳过，另 1 项遭遇 Tk 运行库脚本临时读取失败；该项单独复查通过。
- 静态检查、网页部署资源一致性及 Git 空白检查通过。
- 冻结程序自检、内置模板/网页资源完整性检查、安装包构建及 SHA-256 校验通过。
- 公开模板已移除示例项目、联系人、旧物料及外部工作簿链接。
- 制造输出需要结合实际 PCB、供应商要求及机器角度约定进行核对，自动化回归不能替代工艺验收。

安装包：`EdaKit-0.1.9-Setup.exe`；校验文件：`SHA256SUMS.txt`、`release-sha256.json`。
