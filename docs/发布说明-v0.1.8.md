# EdaKit v0.1.8

## 更新

- Capture BOM 增加钉钉物料总表自动匹配：填写链接、完成登录后自动后台读取，以 Manufacturer_PN 精确匹配编码与类型，保留编码前导零。
- 优化 BOM 页面与工作台生命周期，避免空闲轮询、重复重载及不必要的表格测量；精简测试按钮，将故障诊断折叠。

## 验证与限制

全量自动回归 857 项通过、2 项跳过；静态检查、网页资源一致性检查、冻结程序自检及安装包构建通过。

用户已确认 Capture 自动匹配、BOM 页面响应正常。Allegro 维持原有交互式 BOM 导出功能，本版不提供钉钉总表匹配。

网页读取依赖当前钉钉文档快照结构，非官方企业应用 API；不兼容的格式或权限错误会明确失败。总表仅内存处理，不下载 Excel，不修改源表；浏览器可能保留登录和缓存。

主要实机环境为 Windows 64 位 / Cadence 17.2。Linux 未进行项目整体实机测试。自动更新真实跨版本覆盖安装仍待验收。

## 安装

保存工程并退出 Capture、Allegro，运行 EdaKit-0.1.8-Setup.exe。安装后重新启动 Capture 和 Allegro。SHA256SUMS.txt 提供安装包完整性校验。
