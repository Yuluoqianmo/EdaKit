# 复审优化与本地测试说明 — 0.1.2rc1

2026-10-23。本轮为本地候选版本，尚未提交、推送或发布；不包含本地 `.elibz2` 库导入。

## 已完成

- Excel 部件统一使用 defusedxml，禁止 DTD、实体和外部引用；保留原有工作簿解压大小限制。UTF-8 / UTF-16 编码绕过有回归覆盖。
- iBOM 警告与异常信息写入 HTML 前转义，避免后续加入器件属性时引入脚本注入。
- 自动测试隔离应用数据与默认库路径；专门的 Windows 默认路径断言保留，目录创建使用临时路径。
- iBOM 私有作业及遗留快照在后续导出时按 30 天保留期清理；识别固定命名格式，跳过活动进程、路径链接及近期文件。不会清理用户输出的 HTML、报告或库模型。无法确定进程状态时保留文件。
- Capture 增加 `olb-verify` 成品回读比对，核验器件名、分部、引脚名称、编号、坐标和本体范围；校验失败不放置、不缓存。升级缓存格式，旧缓存需重新生成。
- 更新共享工程 OLB 前保留时间戳备份。共享库成品校验失败记录警告；实际放置仍必须通过独立规范化 OLB 内容校验。
- Allegro 后台构建记录非敏感环境诊断和退出码；发现 `EDA365_SKILL` 时，仅在后台子进程中隔离该启动插件路径，不修改用户启动文件或交互式进程。
- 商城 PCB 预览增加“全部图层 / 焊盘与钻孔 / 丝印 / 装配外形”切换，图层分类复用原生 SKILL 导出的映射。切换保持同一取景范围，不改变生成结果或原始几何，不推测缺失图层。
- 新增 defusedxml 0.7.1，更新锁文件并随包附带 PSF 许可证。

## 参考与范围

参考 [easy2alg PR #3](https://github.com/Yuluoqianmo/easy2alg/pull/3) 的成品校验、后台环境隔离与图层统一思路，以 Python / Tcl 实现适配 EdaKit；没有整体迁移其转换引擎、命名规则或符号编辑器。现有封装几何与 STEP 绑定校验继续保留。

## 请手动验证

1. 关闭 Capture / Allegro，安装候选包后重新打开，确认四个入口及 CEF 关闭重开正常。
2. 选一个普通器件和一个多引脚器件，放置、再次放置、切换器件后放置；确认符号、属性与 PCB 封装匹配。
3. 生成带 STEP 的封装，确认焊盘、钻孔和模型安装方向正常；如后台失败，保留其日志目录。
4. 切换封装预览四种图层并打开大图，确认取景稳定、图层内容符合器件数据。
5. 导入 BOM 模板与编码表，编辑及导出 Excel；导出 iBOM 并验证二维、三维、选择和焊接标记。

Linux 整体运行及 Allegro 17.4 实机行为未在本轮验证。OLB 内容校验覆盖稳定结构字段，不将其等同于 Capture 最终显示外观验收。
