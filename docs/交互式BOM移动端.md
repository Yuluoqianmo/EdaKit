# 交互式 BOM 移动端（v0.1.7）

宽度不超过 1080px 时，使用底部“物料 / 板图”切换，避免整张物料清单把板图推到页面最下方。手机和小平板使用单面板，桌面保留左右分栏。

- 点击物料卡片进入板图并聚焦对应器件。可点“定位选中”再次聚焦，“复位视图”回到整板。
- 二维板图：单指拖动平移，双指缩放并平移，也可使用加减按钮。
- 三维视图：单指旋转，双指缩放并平移；完成标记和选中状态与二维共用。
- 底部可直接标记当前物料完成或撤销，回到物料列表仍保留进度。
- 顶底面切换在板图工具栏提供；导出、清空进度等次要操作放在物料页“更多选项”。
- 手机横屏时，导航移到右侧窄栏，顶部信息与操作压为一行；物料列表改为两列。板图按实际可视比例适配，长条板充分使用横向空间，保持比例、不裁切板框。控件保留可触摸尺寸，兼容安全区。

安装新版后重新导出 HTML，原有 HTML 文件不会自动更新。HTML 仍可离线打开；请使用能执行 JavaScript 的浏览器，聊天应用的附件预览可能不提供完整交互。焊接进度仍保存在当前浏览器本地，换设备或更换文件地址不保证继承。

使用 Edge/Playwright 的手机触屏模拟验证 390×844、320×568、844×390、768×1024 及 1440×900 布局，包含切换、筛选、标记、二维与三维手势、手势后按钮操作和桌面回归。模拟测试不能代替 Android / iOS 真机浏览器验证。

用户已确认本轮手动测试正常，作为 v0.1.7 正式版发布。具体手机系统和浏览器版本尚未记录，不能据此声称全部 Android / iOS 环境均已覆盖。

横屏修正追加验证：844×390、667×375、932×430、568×320；检查两列物料、右侧导航、整板完整显示且利用超过 85% 的板图宽度、聚焦/复位、三维面积和旋转后的状态保留。46 项相关回归通过；竖屏和桌面手势回归通过。
