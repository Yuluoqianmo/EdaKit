# 钉钉网页物料编码匹配

在 Capture 的 BOM Preview 中读取工程，填写物料总表链接，点击“登录并自动匹配”。在系统默认浏览器独立窗口中登录后，浏览器尝试最小化，插件显示读取、校验、匹配和回填进度。无需打开开发者工具、校准控件或操作剪贴板。

支持以 Chrome、Edge、Chromium、Brave、Vivaldi 为系统默认浏览器；其他浏览器明确提示不支持，不自动更换默认浏览器。独立配置目录可能需要重新登录。

总表需含 Manufacturer_PN、新物料编码、Part_Type。只按 Manufacturer_PN 去除首尾空格、忽略大小写后精确匹配，保留内部空格和标点。相同结果合并，不同编码或类型标为冲突。编码保留前导零；未知快照格式、未合并增量、回滚或权限错误会停止匹配。

总表仅在内存处理，不下载 Excel，不修改钉钉源表或 Capture 属性。只有本次匹配结果进入 BOM。浏览器可能保留登录及缓存。折叠的故障诊断提供报告复制与连接关闭，报告记录计数和阶段耗时，不含物料值、Cookie 或令牌。

响应及匹配耗时不包含登录等待；各阶段存在包含关系，不能直接全部相加。未启动匹配时不启动浏览器或匹配轮询，切换工作台不重载同一页面。

用户已确认 Capture 匹配与页面响应正常。Allegro 不提供钉钉总表匹配入口。
