# 安装包构建与验收（2026-10-23）

安装包覆盖 Capture 商城、器件属性、BOM 工作台和 Allegro Interactive BOM。
选择 Cadence SPB 根目录后部署两个插件入口，默认使用 Program Files 下的英文目录。
安装前保存工程并退出 Capture、Allegro；安装器不会自动关闭工程。

## 构建

使用 Python 3.13、requirements-build.lock 中的构建依赖和 Inno Setup 6。构建脚本读取 TOML 需要 Python 3.11+，锁文件与 CI 以 3.13 验证。命令：

```powershell
./installer/build.ps1 -Python C:/path/to/python.exe -Compiler 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe'
```

默认重新构建 GUI/CLI，运行冻结程序自检，再编译安装器。版本从 pyproject.toml 读取。
如使用已验收的二进制，传入 `-UseExistingBinaries -BinaryDir E:/outputs/release-v0.1.1/bin`。
产物 `installer/Output/EdaKit-0.1.1-Setup.exe`，同目录生成 SHA256 清单；构建产物不入 Git。
本轮程序独立构建至 E:/outputs/release-v0.1.1/bin，没有替换用户已安装的程序。

## 安装、升级和卸载

向导可自动发现常见 Cadence 路径，也可手动指定。完整部署要求 Capture tclscripts 和 Allegro IPC 导出程序均存在。
部署使用 CLI 严格模式，Allegro 配置失败不会显示成功；UTF-8 详情见安装目录 deployment.log。
部署失败后保留可卸载的程序文件，修正路径或权限后重装；不宣称事务性自动回滚。

部署目标记录在安装目录 deployment.ini，升级默认沿用。重复安装覆盖程序及插件自有模板，配置块不重复。
同一程序目录切换 Cadence 版本前必须先卸载旧部署。只对选定版本部署，不自动修改所有版本。
卸载移除插件自有模板、Allegro 环境标记块与 iBOM 启动块，保留其他启动内容、用户文件、器件库、配置和导出结果。
Capture.ini 的封装查看路径及首次备份保留，不整份覆盖用户配置。

静默部署支持 `/CADENCEROOT="D:\Cadence\SPB_17.2"`。
`/DEPLOY=0` 仅复制程序，供隔离打包验收使用；不安装插件。
默认需要管理员权限；使用 `/CURRENTUSER` 时需确保所选 Cadence 目录对当前账号可写。
请以实际使用 Cadence 的同一账号运行安装；使用另一管理员账号提升权限的场景尚未验收。

## 本机验收

在 E:/outputs/release-v0.1.1/installer-qa 下的假 Cadence 树验证完整安装、重复安装与卸载，检查真实冻结 CLI 的部署结果。
验证包含插件路径指向安装后的 GUI、标记块不重复、卸载后保留自定义文件和原有启动内容。
假树不代表已在新电脑运行 Capture/Allegro；17.2 的实际功能验收沿用项目现有记录，其他版本仍需实测。
可重复验收脚本为 installer/smoke_test.py；日志与编译器保留在 E:/outputs 下，不纳入源码。

安装器中文翻译来自 Inno Setup 6.7.3 官方仓库：
https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl
保留文件原作者信息。工具下载签名已验证有效；编译器只安装到隔离工具目录。

最终全量回归：674 passed / 2 skipped；冻结程序12项自检通过。安装包约65MB。按用户要求定版为 v0.1.1，提交并发布 GitHub Release。

R2 修复：InitializeWizard 中仅探测 Cadence，不展开尚未初始化的 {app}。旧部署记录延迟到 Cadence 页面读取。补验不传 CADENCEROOT 的初始化分支及安装/卸载成功。R1 的显式路径测试未覆盖该分支；此修复已纳入正式包。

正式包验收命令（workspace 必须为不存在的新目录）：
