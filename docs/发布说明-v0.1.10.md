# EdaKit v0.1.10

本版更新 Allegro 生产交付中的板框选择和 Gerber 输出目录，适用于 Windows 64 位，主要验证环境为 Cadence 17.2。

## 改动

- 优先识别实际图形中的 `OUTLINE`、`DESIGN_OUTLINE`；几何候选不完整时，补充 PCB 层列表中的标准板框层。
- 板框可从实际 PCB 层列表选择，也可手动输入 `Class/Subclass`。PCB 参数页与 Gerber 页同步，重新读取 Film 后保留手动选择。
- `CUTOUT` 不作为自动外板框候选；输入不存在的层仍会阻止配置与导出。
- 修复板框输入框在后台读取或导出结束后重新变成只读的问题。
- Gerber、钻孔及适用的槽铣输出统一放入 `Output files\板名_art`，例如 `BZ_Convert_PWR_art`；不生成 ZIP。
- 保留既有文件覆盖确认、完整生成后再写入输出目录及制造错误检查。

## 使用

更新前保存工程并退出 Capture、Allegro，安装后重新打开。进入 **EdaKit → Production Delivery...**，检查自动选中的外板框层，需要时手动修正，再执行一键设置、核对及生成。

旧的 `Gerber` 目录不会自动移动或删除。此次更名针对新生成的交付文件。

## 验证范围

回归覆盖标准板框优先顺序、错误候选仅有 CUTOUT 时的补充选择、手动输入、两页同步、忙碌态恢复、Film 回读保留，以及目录命名、原有文件保留和失败回滚。最终全量回归与 CI 结果见本次 Release 发布记录。

Linux CI 仅检查自动化兼容性；Linux 安装与 Cadence 集成未进行整体实机测试。板框闭合、实际几何和制造工艺仍需结合工程核对。

安装包：`EdaKit-0.1.10-Setup.exe`。同时提供 `SHA256SUMS.txt` 和 `release-sha256.json`。
