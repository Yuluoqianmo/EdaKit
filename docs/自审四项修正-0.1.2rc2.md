# 自审四项修正 — 0.1.2rc2

2026-10-24。本地候选版本，等待 Capture / Allegro 实机验收后再提交或推送。

1. OLB 成品校验补充 PCB 封装、库引用、位号前缀、分部属性、引脚电气类型与可见性、器件值及自定义属性。修正前同名但封装不同的成品可能被接受，现在会拒绝。
2. 坐标、位置索引等数值字段使用 Decimal 比较，接受不同的等价数字写法，拒绝非法和非有限数值。引脚编号、器件名和属性文本仍精确比较，避免混淆 `01` 与 `1`。
3. 快照复制与子进程启动纳入同一失败清理范围；子进程启动成功后，进程记录写入失败不再删除工作文件。保留输入并尽力写入保守保留标记。
4. 原有 Tcl 测试中的 `olb-verify` 替身改为执行真实 Python CLI；新增 Tcl → CLI 集成反例，验证错误封装和电气类型被拒绝、等价坐标被接受。新增复制失败、启动失败和启动后记录失败的文件所有权测试。

重点手测：升级后重新放置普通及多引脚器件，确认不会误报 OLB 内容不一致；检查 PCB Footprint 与属性；重复打开 iBOM 导出窗口并导出。
