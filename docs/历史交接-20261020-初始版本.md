## 3. 架构

```
商城网页（现代版 index.html / 内嵌版 embed.html）
        │  HTTP / JSONP
Python exe（本地 HTTP 服务 + EasyEDA→Capture 转换 + Allegro SKILL 生成）
        │  文件队列 %LOCALAPPDATA%\lcsc2cadence\queue\req_*.req（key=value）
Capture TCL 插件（capAutoLoad，400ms 轮询 → XMATIC_XML2OLB → PlacePart）
        │
Allegro SKILL（.il，生成 .dra/.psm/.pad + 3D .map）
```

要点：
- 商城与 Capture 是**两个进程**，只有 Capture 进程内的 TCL 能操作原理图，所以用文件队列桥接。
- 队列用 key=value 文本而不是 JSON/socket：Capture 自带 Tcl 无 json 包、socket 不一定可用。

## 5. 电路精灵的关键线索（下一步挖）

对 `D:\DianLuJL\Script\Gtorcad64.dll` 做字符串分析，得到：

1. **顶层菜单**——它用 Tcl 的 `InsertXMLMenu` 注入一级菜单，字符串模板：
   ```
   InsertXMLMenu [list [list "<菜单名>"] ] "1" "<...>" [list "action" "<...>" "0" "Operation" "ShareModule"]
   ```
   且注册快捷键用的 `RegisterAction` 钩子名形如 `"<menuId>)  Alt+S" ...  "Alt+S" "switchStickOrNotStick" "Schematic"`。
   → **Capture 17.2 有 `InsertXMLMenu` 命令**（已在 `info commands *Menu*` 中确认存在），
   下一步在命令窗口试出参数格式即可做顶层菜单。

2. **鼠标点击钩子**——它注册了：
   ```
   RegisterAction "_cdnOrSchViewCmdComplete" "alwaysEnable" "" "MouseClick" ""
   ```
   说明 Capture 在原理图视图命令完成时会回调 `_cdnOrSchViewCmdComplete`。
   → 「跟随光标」很可能借助该钩子/或原生 Move 模式实现，而非 Place Part 面板。

3. 其他字符串：`placePart Part -1 `、`placePart SetProperty -1 `、`.OLBlck`、`Empty.olb`、
   `MenuCommand 57603`（相对坐标菜单）。

**推荐验证路线（按优先级）：**

- **A. PlacePart 后接原生 Move（最接近目标）**
  1. 直接 `PlacePart` 放到任意点（引脚正确）；
  2. 程序选中刚放的器件（尝试 `DboTclUtils_sGetActiveDesignComponents` / 选择集 API / `MenuCommand` 的 Select 类 ID）；
  3. 触发 Capture 原生移动模式（候选：`catch {Move}`、`info commands *Move*`、工具栏按钮对应的 `MenuCommand`；Capture 快捷键 M）。
  若器件能挂在光标上、点一下落位，即为最终方案（几何不受面板影响）。
- **B. 让符号兼容 Place Part 面板**
  面板散乱的模式看起来像把 `position` 当布局偏移用。做变体测试：全部引脚 `position="0"`、
  或 `position` 每 4 个循环一次、或去掉 CommentText 只留原生名字/编号，看面板是否正常。
  若找到兼容写法，则沿用面板的跟随光标体验。
- **C. 外部窗口事件**（电路精灵 DLL 里有 `SendKeys`/`SendMessage`/`PostMessage` 字符串）
  从 exe 侧对 Capture 发送真实键盘/鼠标事件（如放置后自动按 M 并跟随）。
  脆弱但兜底可行；需处理窗口焦点与 DPI。

## 9. 踩坑清单（务必先读）

1. **TCL 模板必须纯 ASCII**（中文用 `\uXXXX`）。Capture 按 cp936 读文件，UTF-8 中文
   尾字节会变成 `{}` `\`，整个文件解析失败。
2. `XMATIC_XML2OLB/OLB2XML` **返回值不可信**，成败只看文件系统。
3. 写已存在 `.olb` 前必须 `file rename` 挪走，否则静默不写。
4. `PlacePart` 坐标单位是**英寸**；`(500,500)` 是页面外，`ZoomAll` 永远看不到。
5. PlacePart 后必须 `ZoomRedraw`/`ZoomAll`，否则画面不刷新。
6. 库按**路径**缓存：同一路径内容变了，Capture 仍用旧内容 → 换库名或重启 Capture。
7. 工程 Design Cache 会缓存同名器件，旧坏件会顶掉新库 → 新工程/清页测试。
8. 直接写出的库需经 `OLB2XML→XML2OLB` 规范化，否则放置后引脚散乱。
9. Place Part 面板对自绘符号实例化有缺陷（引脚散），面板路径暂不可用于最终交付。
10. `MenuCommand` 需要原理图视图活动；页签（商城/库窗口）活动时报 Message Not Processed。
11. `ChangeActiveWindow`/`GetWindows` 在这台机器上无效，无法用 TCL 切活动窗口；
    只能靠「挂起 job，等用户切页签后轮询补放」。
12. 这台 Capture **没有 Tk**；输出走命令窗口 + `lcsc2cadence.log`。
13. `deploy` 从 exe 里解模板：改过 TCL 没重建 exe 时，**不要用 deploy**，手拷 `plugin_tcl\`。
14. pytest 系统临时目录在用户机上会 WinError 5 → 用 `--basetemp`（构建脚本已处理）。
15. PowerShell 里 `dist\lcsc2cadence.exe`（已在 dist 内）会报“无法加载模块 dist”，用 `.\lcsc2cadence.exe`。
