## 2. 统一显示规则

- 分类名采用商城中文习惯；电路参数保留工程上必要的缩写与符号，例如 ESR、CMTI、Iq、tPHL、tPLH、RDS(on)。
- 型号、品牌、封装代码、协议、单位和具体数值保持：0603、HTSSOP-20-EP、RP2040、I²C、SPI、USB、±1%、4.7kΩ 不进行生硬翻译。
- 翻译只作用于显示 label。请求中的 categoryId、原始属性 key、原始 value、商品编号与封装筛选条件完全保持；选项值不转换单位或正负号。
- 同义键可共用译名但保持独立参数身份，例如 Quiescent Current (Iq) 与 Quiescent Current(Iq)、Output Current 与 Output current。空白、大小写、上游拼写错误仅用于显示别名匹配，不能回写修改请求。
- 显示时优先“叶分类 + 原始键 + 实际枚举语义”，其次通用译名。没有依据的字段保留原文辅助说明并收集待核项，避免伪造专业含义。
- 属性下拉框、全部参数、已选条件、查询摘要和器件详情统一走同一显示词库。英文原文可放在悬停提示中，方便对照手册。
- 值不存在、数据异常、无手册、无 3D 模型和加载失败分别显示；不能用“暂无”掩盖请求错误。

## 3. 必须按上下文区分的项目

| 原始词 | 建议处理 |
|---|---|
| Output Type | 必须按类别和实际枚举值选显示名：可调/固定属于输出电压类型；开漏/推挽属于输出形式。没有判定依据时显示“输出类型”，保留原文。 |
| output type | 与 Output Type 共享显示词库候选，但原始键独立保存，不能合并请求参数。 |
| Energy Efficiency | 1007 的示例值为 94%、99%，建议“转换效率”，不译为“能效等级”；与 Conversion Efficiency 即使同名显示也不合并筛选键。 |
| Temperature Coefficient | 电阻 ppm/℃ 显示温度系数；若电容出现 X7R/C0G 等，应单独核对为介质/温度特性，不按 ppm/℃ 理解。 |
| Tolerance | 商城通用入口可用“精度”；细分类可显示阻值精度、容量偏差、感量偏差。维持数值和正负号。 |
| Function | 按类别细化为转换功能/逻辑功能/功能，禁止全局替换为“转换功能”。 |
| Class | 257 的聚合值同时有 Class D 和 Inductance-to-Digital Converter，语义不统一；必须下钻叶分类核对。 |
| Con | 接口/专用 IC 样本单位为 pF，暂拟导通电容；需要叶分类和对应手册确认 Con 定义后启用。 |
| Drain Current (Idss) | 191 为 JFET 聚合分支却返回 nA/μA，须查具体型号区分零栅压漏极电流与漏电流；不能直接套用任一解释。 |
| Photoperceptivity | 样本为 klx，暂拟照度检测范围；不能直接译成单位 A/W 的光响应度，需要对应器件手册确认。 |
| Resolution (Bits) | 255/257/264 样本混入 kHz/MHz；保留原值并标注上游数据异常，不擅自改成采样率或改写单位。 |
| Logic Family | 264 的样本 ADATE304 看似型号，不是通常逻辑系列；需要型号核对与上游数据核查。 |
| Number | 191/186 的值为 1 N-channel、2 N-Channel 等，不能只显示“数量”而丢失沟道含义。 |
| High level Delay Time | 不能仅凭 High level 断定 tPLH 或 tPHL，须看测量定义。 |
| Low level Delay Time | 不能仅凭 Low level 断定 tPLH 或 tPHL，须看测量定义。 |
| Switching Voltage(Vs) | 187 的晶闸管分支须确认 Vs 的转折/开关定义，暂保留符号，不等同额定工作电压。 |
| Integrated Power Output Voltage | 专用 IC 样本有 3~3.5V 等，拟集成电源输出电压，需要具体器件确认是否隔离电源。 |
| Core Size | 258 MCU 分支拟内核位宽；不能将任意类别的 Core Size 都解释为位宽。 |
| Input Logic Level - High | 当前样本为 V，拟高电平输入电压；需看手册区分 VIH 阈值与其他测试电压，不直接补典型/最大/最小限定。若出现 CMOS/TTL 等值，按上下文显示逻辑标准。 |
| Input Logic Level - Low | 当前样本为 V，拟低电平输入电压；需要手册确认 VIL 阈值，不能混作逻辑标准。 |
| Input Logic Level -Low | 上游缺空格的独立原始键；仅显示别名可共用。 |
| Output Logic Level - High | 当前样本为 V，拟高电平输出电压；需核对 VOH 与负载/供电条件，不与 CMOS/TTL 逻辑标准混同。 |
| Output Logic Level - Low | 当前样本为 mV，拟低电平输出电压；需核对 VOL 与负载/供电条件。 |
| Channel Type | 261 的枚举为 Bidirectional/Unidirectional，表示通道传输方向，不能译为 MOSFET 的沟道类型。遇到其他类别要按实际枚举再核对。 |
| Voltage Reference | 当前枚举 Built-in/External/Internal or external 指基准电压来源，区别于 Voltage Reference Value 的基准电压数值。 |
| Current - Output High(IOH) | 保留电流符号与正负号，不将所有 IOH 都无条件改写成正值拉电流。 |
| Current - Output Low(IOL) | 保留电流符号与正负号，不将所有 IOL 都无条件改写成正值灌电流。 |
| Propagation Delay tpHL | 方向按输出波形由高到低定义，不按输入方向猜测；缩写保留。 |
| Propagation Delay tpLH | 方向按输出波形由低到高定义，不按输入方向猜测；缩写保留。 |
| Settling Time | 模拟量稳定到精度范围的建立时间，与数字时序 Setup Time 含义不同；可在提示中解释。 |
| Setup Time | 数字时序建立时间；不得与 Settling Time 合并筛选。 |
| Antistatic Capacity | 抗静电能力；即使样本为 V 也不能擅自补 HBM/CDM 等测试模式。 |
| Isolation Voltage(Vrms) | 保留 Vrms；不等同持续工作隔离电压或浪涌隔离电压。 |
| Applicable to AC-DC Architecture | 样本 Flyback 对应反激拓扑；即使出现在 DC-DC 分支，也不能仅因分类名而隐藏该字段。 |
| Single Supply | 样本与单位核对后使用单电源供电电压；不是“只支持单电源”的布尔判断。 |
| Single supply | 大小写变体保留独立原始键。 |
| Dual Supply | 保留正负供电范围原值，不能省略负号。 |
| EEPROM | 按当前 MCU 容量样本拟名；遇到布尔枚举需改用是否集成 EEPROM。 |
| Combining Form | 聚合样本只有 Combination，暂拟组合形式；需要叶分类和具体器件核对。 |

## 9. 3D 等待问题的独立方案（保持暂不执行）

现有审计观察到：拖动松开后请求新角度 PNG；同一器件 4 次本地 PNG 请求只下载 1 次远端 OBJ。鼠标移动期间只记录角度增量，不是每个 mousemove 都下载。当前提示把本地重新渲染也说成下载，且请求前隐藏旧图，因此容易被理解成反复下载。

建议顺序：①区分首次下载、解析、角度渲染等提示并保留上一帧；②按模型和角度管理有限缓存，统一实际渲染尺寸作为缓存键；③拖动时低分辨率、松开后精细渲染，采用请求序号丢弃过期结果；④再评估大模型后台预生成常用视角。旧内核兼容方案优先，WebGL 需单独验证宿主支持。以上只做方案，没有改动实现。

本机审计样本：LM5116 的 OBJ 约 1.34 MB / 35,072 个面，新角度 1024 级渲染约 0.65–0.75 秒，512 级约 0.36 秒；只代表本机此模型，不能外推所有器件。现有 2048 请求实际被封顶到 1024，但缓存键仍区分二者，可产生重复计算。
