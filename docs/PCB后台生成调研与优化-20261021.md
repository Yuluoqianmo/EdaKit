# PCB 后台生成调研与优化

## 调研依据

1. 用户提供的本地《PCB封装命名规范》：常规被动件按 R/C/L + 尺寸码，IC 按类别、脚数、间距、尺寸及 EP，特殊同尺寸变体另行区分。采用其分类思想，增加确定性几何摘要，避免手工 A/B 序号依赖建库顺序。
2. Footprint Expert 官方 Allegro 输出说明：https://www.pcblibraries.com/products/fpx/userguide/default.asp?ch=205
   - 输出脚本、设备文件和自动运行批处理，再由 Cadence 生成 PAD/DRA/PSM；官方未将此流程描述为脱离 Cadence 的直接二进制导出。
   - NoGraph 可关闭图形显示；多产品许可证选择可能使后台等待。设置明确产品及超时，错误显示日志目录。
   - Parts Per Script 可摊薄大量器件的启动成本；本轮仍为单任务后台进程，未实现批量或常驻许可证工作进程。
3. Footprint Expert 官方产品架构：https://www.pcblibraries.com/FootprintExpert/
   - 稳定的器件尺寸数据与可变化的库规则分离，已有数据可检索、复用、重新构建。
4. GitHub KiCad-to-Allegro-Footprint-Converter：https://github.com/Kononenko-K/KiCad-to-Allegro-Footprint-Converter
   - 已阅读 README 和 kicad2allegro.py：按独特焊盘生成 Padstack Editor 脚本，再用 SKILL 建立封装；24.1 Qt UI 脚本对本机 17.2 不可直接照搬。
   - 借鉴明确分离几何转换和原生实现。其圆角/长圆孔近似策略不适用于当前项目的严格转换要求。
5. GitHub cadence-footprint-automation-framework：https://github.com/Richard-cc172/cadence-footprint-automation-framework
   - 阅读其公开工作流：规格、原生构建、实际提取与比较分离。其发布的测试数字不是本项目验证结果。
6. 本机 Cadence 17.2 官方手册：`D:/Cadence/SPB_17.2/doc/acoms/achap.html` 的 allegro 命令以及 `doc/algroskill/01ovrvew.html` 的 Running AXL-SKILL in Batch Mode，列出 -nograph/-nographic 和批处理脚本入口。

## 已实施

- 可读通用命名、与料号无关的几何身份，详见《封装库命名规范》v2。
- 原生编译启用 -nograph，保留独立进程、明确产品、safe、超时/取消及结果校验，不接管用户打开的设计。
- 升级后的厂商模板缓存到配置 PCB 库的 `.edakit-cache/native-template`。缓存键含安装路径、原模板 SHA256、dbdoctor 大小和修改时间；缓存内容另验 SHA256。损坏或版本变化自动重建。
- 首次新几何仍需原生编译；重复或跨料号相同几何校验通过即可复用，无 Cadence 启动。
- 标准焊盘身份移除不参与实际生成的绝对角点，合并重复焊盘创建。
- 界面显示查找复用、准备环境、后台编译、核对保存的实际阶段，结果显示实际耗时及实际小写文件名。轮询间隔改为 400 ms。

## 验证与使用

真实输出及耗时以本轮最终验证记录和《项目交接》顶部为准。测试使用隔离库，覆盖 C25804 的 2 脚、C2040 的 57 脚、含空格路径和模拟另一料号复用相同真实电阻几何；后者是复用机制测试，不冒充第二颗真实料号样本。

本机最终结果：C25804 `R0603_8B60B08CF2` 首次 16.578 秒；C2040 `QFN57_0D4_7X7_EP_31404E796A` 18.578 秒且复用已升级模板；模拟另一料号复用电阻 0.002 秒，无进程启动。两个样本共 3 个 PAD。输出在 `E:/outputs/edakit generic background final`，机器证据在 `E:/outputs/edakit-generic-native-final.json`。时间包含准备、原生编译、校验及发布，不含前端轮询等待；不能据此承诺其他机器相同速度。

最终全量回归 451 passed、1 skipped（51.91 秒）。冻结 CLI 11 项自检通过；四个改动 Python 模块及冻结网页资源与最终源码核对一致。Playwright + Edge 模拟接口在 1440×900、808×850、808×600、390×844 验证设置读取/保存、生成忙状态、阶段文本、复用结果/2 毫秒、真实小写文件名、失败恢复。页面身份、非空白、无错误遮罩、脚本控制台、截图和交互均通过。Browser plugin not available，使用现有 Playwright，不新增浏览器依赖。本机截图目录 `E:/outputs/.edakit-ui-qa/auto-result-*.png`，808×600 结果截图已人工查看。模拟接口 UI 检查与上述原生构建是独立证据，尚未进行本轮用户工程交互 DRC。

用户更新插件后：在“库设置”确认目录，重新放置测试器件，点击“生成 PCB 封装”。首次等待后台完成，重复点击应显示复用和较短耗时。然后按既有流程导出网表、导入 PCB，核对新命名、焊盘及 DRC。原生创建/编译/编号坐标校验已自动运行；实际交互放置和当前工程 DRC 由用户验收。

目前仍为已有封装数据的转换，不是由尺寸参数重新计算 IPC 焊盘。未来参数化生成应独立保存尺寸规格与设计规则，再复用本轮的几何身份、后台编译及注册发布。当前不承诺所有新几何立即输出，不宣称无许可证依赖。
