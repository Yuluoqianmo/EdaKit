## 用户验证：依次操作

### 1. 保存工程，关闭旧服务

保存原理图并退出 Capture，关闭 EdaKit 页面和独立窗口。在 PowerShell 执行：

```powershell
Get-CimInstance Win32_Process |
  Where-Object { $_.Name -eq 'edakit.exe' } |
  Select-Object ProcessId, ExecutablePath, CommandLine
```

预期没有旧 EdaKit 服务。如果仍有，请根据显示的路径与命令行，在任务管理器结束 `E:\outputs\edakit\dist\edakit.exe` 对应的旧服务进程，再重新进入。不要结束其他项目的进程。

### 2. 核对版本并自检

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'E:\outputs\edakit\dist\edakit.exe'
& 'E:\outputs\edakit\dist\edakit.exe' selftest
```

预期哈希为本文开头的 `F9A50B…A42591E`，自检 11 项通过。无需安装 Python，无需重新部署插件。

### 3. 检查多参数中文与布局

重新启动 Capture，打开工程，从 **EdaKit → LCSC Mall** 进入。

1. 清空关键词，选 **电源管理 → DC-DC 开关控制器**，点击“全部参数”。
2. 查看“调光方式、驱动配置、最大占空比、转换效率、反馈方式、开关频率、输入电压、工作电压”等标题。该类别本次返回 33 项，实时数量允许变化。
3. 滚动到底部，确认后续参数可读，“完成选择”“应用并查询”始终可操作。缩小窗口后重复，检查文字未被横向滚动条遮挡。
4. 将鼠标停在参数标题上，预期可查看原始英文与必要说明。遇到“待核对”，提示应解释语义或数据异常，原值应保留。

### 4. 检查中文选择与真实查询

1. 在“输出电压类型”下拉框搜索 `Adjustable`，再搜索 `可调`，两次应找到同一个选项。
2. 选择“可调”，点击“应用并查询”。预期已选条件与查询摘要显示中文，结果可以正常返回。
3. 有多页时点击下一页，预期条件保持，结果继续返回。选择结果，详情参数应显示中文；品牌、型号、封装不应被翻译。
4. 如当前类别存在“功能特性”，打开并检查有对应译名的完整选项；未覆盖的技术值保留英文，不应被截断替换。

### 5. 回归 4.7K 电阻及专业语义

1. 选择 **电阻 → 贴片电阻**，关键词输入 `4.7K`，封装选 `0603`，精度选 `±1%`，点击“查询”。如果精度在“全部参数”，从该面板选择。
2. 预期能找到器件，结果封装为 0603，详情/描述阻值为 4.7kΩ，已选条件正常；不要要求结果数必须等于 150。
3. 切换电容或电感分类，若存在相应字段，应分别显示“容量偏差”或“感量偏差”；电容介质示例 X7R/C0G 保持原值。
4. 如测试逻辑类器件的“输出形式”，检查 Open-drain 对应“开漏”、Tri-State 对应“三态”。原始单位、正负号、tPHL/tPLH 保持正确。并非每个分类都有这些字段。

### 6. 检查既有功能

单击一个 0603 电阻，切换 PCB 封装/原理图符号，检查图片、缩放和大图；点击“数据手册”确认能打开对应资料。点击“放置”，切回原理图，移动鼠标应有器件跟随，单击可落位、引脚正常，按 Esc 退出。此步骤会在你的工程新增器件，可用测试页并在测试后撤销。

本轮没有优化 3D 拖动等待，不将其等待文字或耗时变化作为本轮通过条件。若需要测试网络等待，观察查询过程是否有等待反馈、失败时是否能重试，不要反复点击提交。
