## 2. 放置按钮与默认光标行为

搜索 C25804，单击选择并等待预览加载。预期按钮仅显示“放置”，为紧凑普通按钮，不再横跨详情栏。
点击“放置”，切回原理图页签，把鼠标移入绘图区。预期器件跟随光标；单击落位，引脚正常；按 Esc 退出连续放置。再用 C2040 重复验证。不需要额外选择跟随光标模式。

## 3. 分类范围

展开一级分类，预期只出现电子设计相关分支（当前上游快照保留 26 个一级类）。不应出现五金/紧固件、办公用品、物料搬运、工业自动化与控制、工具耗材等综合用品分支。
保留无源器件、IC、分立半导体、保护器件、连接器、电池、电源、开发板、光电、射频、传感器等。
选择“无源器件 → 电阻器 → 贴片电阻”，检查结果刷新；再选 IC 分支检查下级分类正常。原始分类 ID 与层级保持不变。
本轮筛选范围为分类导航；关键词和 C 编号搜索保持原有搜索行为，不对商品分页结果做事后删减。
