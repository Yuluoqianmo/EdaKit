# Allegro 生产交付

在当前 PCB 中选择 **EdaKit → Production Delivery...**。勾选需要生成的内容，核对制造参数与输出路径，点击生成查看处理进度。

## 输出内容

| 项目 | 内容 |
| --- | --- |
| Gerber | 当前工程光绘、钻孔及适用的槽铣输出，保存在 `Gerber` 子目录 |
| 器件坐标 | 封面＋坐标表，列为 REFDES、COMP_DEVICE_TYPE、COMP_VALUE、COMP_TOL、COMP_PACKAGE、SYM_X、SYM_Y、SYM_ROTATE、SYM_MIRROR |
| 加工说明 | PCB 制板要求与钢网说明 Excel |
| iBOM | 可离线使用的交互式 HTML，支持板图定位、3D 和焊接进度 |

默认输出到 PCB 所在目录的 `Output files`，已有同名目录直接复用。无需压缩；可另选输出目录。勾选覆盖后会提示确认，仅替换本次生成的同名文件。

## 坐标与封面

坐标单位为毫米，顶底面均保留原始 XY 和旋转角度，不对底面额外镜像。SYM_MIRROR 为 T 或 B。这复现已核对的历史坐标文件，不代表所有封装放置原点均为贴装中心。

在“输出文件”页的器件坐标卡片下，展开“坐标文件封面信息”。可填写工程名称、文件编号、正式/临时、版本、日期、编制、审核、批准和更改项。日期默认取本机当天，其他填写信息按工程保存。收起表单不会丢失内容。

Capture 的 BOM 在“导出设置 → 封面信息”填写对应字段；制表人与日期沿用 BOM 主表单。旧单页模板自动导出带封面的新版布局。

## 制造参数核对

PCB 叠层、尺寸等读取值属于设计参考，不应直接视为已确认的采购要求。核对 PCB 参数、钢网和 Gerber 页面；Film 写入按界面提示执行。日志中的动态铜皮过期等阻断错误会终止交付，需在 Allegro 中处理后重试。

只有所选内容全部生成和检查完成后才写入交付目录。存在制造警告时应查看日志，实际线宽线距、孔槽、层序和贴装角度仍需按制造商要求检查。

## 使用 iBOM

在输出文件页勾选 iBOM，再到 iBOM 页选择板内属性或外部最终 BOM。关联外部 BOM 可按位号带入物料编码。Allegro 钉钉自动匹配未启用。

安装或更新后重新启动 Cadence，并重新生成 HTML。原有 HTML 和 Excel 不会被程序更新自动改写。
