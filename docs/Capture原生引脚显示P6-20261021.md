## 修改内容

- 名称来自 SymbolPinScalar.name，编号来自 PhysicalPart/PinNumber。启用原生 Pin Name Visible（有效名称）、Pin Number Visible，停止生成替代引脚标签的 CommentText。名字等于编号的阻容/连接器仍默认隐藏冗余名称，用户可打开显示。
- 所有引脚输出 IsLong=1（Line）；连接端向外延长，至少保留 100 mil 引脚线，本体端沿引脚方向保持原位。
- 连接点相对符号原点均对齐 100 mil 整数网格；沿同侧排序消除拥挤冲突，不改变物理编号或源电气类型。最终摆放位置仍须开启软件吸附进行实测。
- 缓存格式和正式零件后缀升级到 P6，避免误用旧库。
- 新增回读检查器，校验转换前后 57 个引脚的编号、名称、电气类型、连接点、本体端、Line 标志与全局可视开关。

不再用额外文本掩盖原生名称旋转或排版问题。原生顶/底名称旋转、文本间距及最终 Line 显示须在 Capture 中确认，若仍重叠，应继续调整原生布局。未重新打包或覆盖当前 exe。

## 人工验收

1. 编辑刚放置的 P6 符号，检查几个方向的引脚 Shape 均为 Line。
2. 关闭 Pin Name Visible、Pin Number Visible，所有引脚名称和编号应消失；重新打开后各显示一次。修改一个测试引脚名称，显示应同步变化，不应残留旧标签。
3. 打开格点吸附，设置 Pin-to-Pin 为 0.100 inch（100 mil），在原理图检查相邻 GPIO 引脚落在连续网格上。从物理引脚 1、38、57 分别拉线，确认连接端吸附。库编辑器外观不替代原理图连线验收。
4. 确认顶/底名称与编号没有重叠。任一问题仍在，反馈 P6 名称、Shape 和可视开关状态，以及回读检查结果。
5. 三项通过后继续之前的网表生成、PCB 导入和网络映射测试；当前尚未宣称这些验收通过。
