# PCB 封装插件入口（P9）

## 操作

1. 保存工程，重启 Capture，打开 EdaKit 工作台。
2. 点击“库设置”，填写原理图库和 PCB 封装库的完整目录并保存。Cadence 安装目录可留空自动检测，或填写例如 `D:/Cadence/SPB_17.2`。
3. 选择元件并点击“放置到原理图”，库写入所设目录下的 `EdaKit.olb`，中间文件位于 `.edakit-staging`。
4. 点击“生成 PCB 封装”，已有同类同几何封装时校验后直接复用；新几何通过独立 Allegro NoGraph 后台自动创建、保存、编译和检查，无需输入 SKILL。状态栏显示实际阶段，结果窗口显示完整库目录、实际小写文件名及耗时。
5. 新放置器件的 `PCB Footprint` / `PCBFootprint` 与本次输出名一致。沿用已经通过的网表导入流程测试。

首次生成需可用的 Allegro PCB Designer 许可证。独立进程使用私有模板和启动目录，不加载用户当前板文件。无许可证、超时、未完成编译或引脚不一致均显示失败，不发布半成品。

保存设置维护 Allegro 用户 env 的标记块，保留其他配置；已打开的 Allegro 需重启读取新路径。若关闭 `auto_config_allegro`，自行配置 psmpath 和 padpath。含空格路径使用引号。

## 兼容与输出

规范见 [封装库命名规范](封装库命名规范.md)。P9 沿用 P7 的 100 mil 连接点、300 mil Line 引脚和原生名称/编号显示，厂家型号和 PartValue 保留来源值。旧工程实例和库不自动迁移，需要新规则时重新放置。

- 正式库根目录：`.dra`、`.psm`、`.pad` 和 `edakit-library.json`。
- `.edakit-builds/<CID>/<时间戳-随机标识>`：隔离脚本、日志和编号映射，失败时保留用于定位。
- `.edakit-cache/native-template`：已升级厂商模板缓存，带版本及 SHA256 校验；损坏时重建。
- 注册表保留完整几何摘要、引脚数和文件 SHA256。匹配且文件未修改时直接复用。
- 同名文件冲突或被手动修改时保留原文件并报错，不强行覆盖。
- 仅在原生编译完成、文件非空、引脚编号和坐标一致后发布；不等同于制造验收或所有 DRC 检查通过。
- ARC、独立孔、未知层等未支持数据明确拒绝，不静默省略。
