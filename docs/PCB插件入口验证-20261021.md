# PCB 封装插件入口

工作台新增“生成 PCB 封装”。输出为候选脚本，需在 Allegro 中编译，不表示 `.psm` 已通过验收。

1. 保存工程，重启 Capture，打开 EdaKit 工作台。
2. 搜索 C25804，选择元件并点击“生成 PCB 封装”。成功后自动打开输出目录，弹窗给出目标封装名、`.dra` 路径及 `skill load(...)` 指令；目录内 BUILD.txt 保存相同指令。
3. Allegro 中 File → New，Drawing Type 选择 Package symbol，Drawing Name 使用提示的完整路径。在 Command 输入框执行提示的 `skill load("完整路径/manual_build.il")`。不要在板文件中运行。
4. 检查 `.pad/.dra/.psm`、物理编号及 R* 位号，关闭重开 `.dra` 核对。失败时保留首条错误，不对半成品反复加载。
5. 新放置原理图元件的 PCB Footprint 与输出名一致。导入 PCB 前将本次目录加入 Allegro 的 psmpath 和 padpath，再沿用已通过的网表导入流程；旧实例不自动更新。

输出位于配置封装库上一级的 `pcb-candidates/<CID>/<时间戳-随机标识>`。每次使用新目录，不覆盖已有成果；pinmap.json 保存编号配对、源名称和输出名称，状态为 candidate。

P8 沿用 P7 格点、Line、原生名称和编号，升级身份防止旧 PCB Footprint 属性被缓存。含点号、非法字符或超过 31 字符的源封装名统一规范化，Capture 与 Allegro 共用。已有 C2040_QFN56_EP 测试板不改写。

不支持的 ARC、孔及图元明确报错，不能静默遗漏。C23630 离线电容样本包含 ARC，当前会拒绝生成。尚无跨器件同名异几何的库发布注册机制，请勿混用不同候选目录中的同名封装。

验证：433 passed / 1 skipped；冻结 CLI 11 项自检通过。Browser 插件不可用，采用现有 Playwright + Edge，以模拟接口响应检查 1440×900、808×850、390×844 下按钮初始禁用、选择后启用、忙状态防重复、成功及错误恢复。后端真实离线样本和 HTTP 测试验证配对及命名。新增入口的 Cadence 真机验收待用户执行。
