# 关于、更新与诊断

通过 Capture 的 EdaKit → About EdaKit 打开独立关于页面。显示运行版本、许可、GitHub 仓库、发布说明和问题反馈地址；不占用商城、器件属性及 BOM 的工作台标签。

## 更新

可手动检查更新，也可设置启动时自动检查，每 24 小时至多自动尝试一次。只识别仓库正式 Release 中高于本地版本的三段数字版本，不提示降级。断网或限流显示检查失败。

安装包名必须为 EdaKit-X.Y.Z-Setup.exe。下载仅允许指定 GitHub HTTPS 地址，使用 Release 资源 digest 或同次发布的 SHA256SUMS.txt 校验 SHA-256。支持下载进度和取消。校验用于完整性检查，不等同于发行者代码签名。

点击安装并确认后，独立更新助手等待 Capture、Allegro 和旧服务退出，不强制关闭软件、不代替用户保存工程。最长等待 30 分钟，等待中可取消。保留原安装范围和 Cadence 路径，按需显示管理员权限确认，然后打开安装向导。

安装失败会保留 installation.log、result.json；成功要求安装器退出成功且安装目录 CLI 返回目标版本。没有自动回滚或自动重启 CAD 功能。更新状态和下载保存在 %LOCALAPPDATA%/edakit/updates。

真实跨版本覆盖更新尚未完成实机验收。元数据、下载校验、取消、助手交接、安装范围及失败处理已有自动化测试；这些测试不能代替完整跨版本安装验证。可从 Releases 手动下载安装包。

## 诊断和日志

关于页提供“环境诊断”和“打开日志文件夹”。原插件 Diagnostics 子菜单已移除，后台日志保留。

环境诊断仅在点击时触发，通过当前 Capture 会话队列检查原生能力，结果显示在页面并写入日志；不需要先读取器件表或打开设计。不在打开工作台时自动扫描。保留 edakitProbe 控制台命令供排障使用。

日志目录为 %LOCALAPPDATA%/edakit，包含 edakit.log、service.log 等。打开文件夹的服务端接口仅接受固定应用目录。反馈前请检查日志并移除敏感工程信息。

关于页、诊断桥接和错误恢复已通过自动化回归；当前诊断按钮仍需 Capture 实机验收。

## 发布约定

源码、程序模块、CLI 和安装器版本保持一致。使用 vX.Y.Z 标签，提供同版本 EdaKit-X.Y.Z-Setup.exe 和 SHA256SUMS.txt。已发布附件不覆盖。
