# PCB 扩展能力与器件验证

更新：2026-10-22。本轮扩展已接入工作台原有“生成 PCB 封装”按钮。当前采用源 CAD 几何转换，不是 IPC 参数计算器，也不能承诺任意器件都可转换。

用户反馈（2026-10-22）：已完成测试，功能正常。此反馈对应当前部署版本；未逐项提供器件与操作清单，具体自动验证证据及适用边界仍见下文。

## 本轮实现

- 多边形铜焊盘：转为独立 Cadence shape symbol（SSM），与 DRA、PSM、PAD 一并发布和校验摘要，避免只复制封装后丢失铜形。
- 原生圆角矩形焊盘，保留圆角半径；矩形、圆形、长圆形继续支持。
- 镀铜槽孔和非镀铜槽孔：保留长宽、方向、局部钻孔偏移、镀孔属性；独立 HOLE 和明确的无号 NPTH 单独统计，不增加电气引脚。
- 阻焊扩展、钢网缩减及关闭开窗；独立阻焊/钢网 PAD 开窗作为图形生成，不新增电气编号。
- 非铜填充支持相对路径、多轮廓、曲线、复合轮廓内孔和同层 cutout。曲线按 0.001 mm 弦误差离散，输出坐标精度 0.0001 mm；内孔使用三角剖分保留空白。
- 预览同步显示异形焊盘、槽孔和填充区域。编号、坐标、槽孔尺寸/偏移/镀孔属性通过实际 Allegro 数据库回读校验。
- 原生库缓存检查覆盖形状依赖。原理图与 PCB 保留物理编号字符串，不补号、不重排、不把 NC 或机械孔猜成额外电气引脚。

## 用户测试：直接在插件内操作

1. 保存当前工程，退出全部 Capture，再重新打开，确保加载新程序。
2. 在插件库设置中确认路径。首次默认 `D:/EdaKit/Libraries/Symbols` 和 `D:/EdaKit/Libraries/Footprints`；已有自定义路径继续保留。
3. 优先搜索 **C165948**，选中后点击“生成 PCB 封装”。观察底部操作信息直到成功；无需输入 SKILL 指令。再点击一次，应提示复用已有封装。
4. 放置该器件的原理图符号，在一个测试工程内生成网表并导入 PCB。检查下表对应的焊盘、槽孔、机械孔和引脚编号。

## 明确边界

- 通孔/槽孔尚未定义负片电源层 ANTI/THERMAL。重开后数据库检查提示 GND/VCC 缺少隔离盘；必须按工程规则配置后再用于负片层。插件成功和复用提示中均显示此限制，不自动猜测隔离间距。
- 同一物理编号出现在多个不同位置、或同层同号包含不同铜形时仍阻断。例如本轮源数据 C456012、C319160；需显式的复合引脚/外壳映射方案，不能自动删盘或补号。
- 铜 SOLIDREGION、COPPERAREA、VIA、KEEPOUT、区域式 NPTH 铣槽、未知层仍阻断。独立 PAD 槽孔与区域铣槽不是同一个模型。
- 自交、退化、无法解释的挖空、超过离散精度或复杂度上限的路径，以及非轴向槽孔均明确报错。
- 自定义焊盘要求一个连通、无内孔的铜轮廓；多片或带孔铜形不自动近似。
- 椭圆 ARC 等此前尚未支持的图元仍需另行实现。支持圆形 ARC 不代表支持全部椭圆弧。
- 完整自定义焊盘导出使用插件自动编译链路；旧 CLI 单独导出 SKILL 遇到形状依赖会提示改用插件，避免输出缺依赖的脚本。
- 不包含 IPC 公差计算、任意封装族参数编辑器或厂家尺寸手册自动审核。上游数据缺失/错误仍可能影响结果。

## 技术依据

本机 Cadence 17.2：`doc/algroskill/06intedt.html` 的 axlDBCreatePadStack（圆角、shape symbol、slot、offset、plating）；`03dbcre8.html` 的 axlDBCreatePin（机械孔空编号）；`14dsnctl.html` 的编译、打开和数据库检查 API。实际圆孔 drillSizeWidth/Height 为零，回读以 drillDiameter 补足；镀孔属性统一大写后比较。

EasyEDA 字段对照 KiCad 官方导入器的固定提交 `36d8d95724b237169bda3395ccad824d70732d0b`，文件 `pcbnew/pcb_io/easyeda/pcb_io_easyeda_parser.cpp`：PAD[9] 为孔半径，[13] 为槽总长，[14] 为槽中心线端点，[17] 为钢网扩展，[18] 为阻焊扩展；HOLE 的数值为半径。仅核对格式事实，未复制 GPL 实现代码。

新增运行依赖 Shapely 2.2、svgelements 1.9.6；NumPy 为间接依赖。第三方许可及 GEOS/Windows 二进制许可已放入 `licenses/*-third-party.txt` 并随程序打包。
