# EdaKit v0.1.0

2026-10-23 首个正式安装版。用户已完成当前安装包及功能的初步测试。

## 功能

- Capture 内嵌商城工作台：器件搜索、符号/封装/3D 预览、放置器件，PCB 封装自动生成与 STEP 模型绑定。
- 工程器件属性表：原生属性名称、自定义字段、排序筛选、批量编辑与同步到 Capture。
- 中文 BOM 预览及 Excel 导出：模板抬头编辑、按 Manufacturer_PN 匹配公司物料编码、手工补充及增减物料，允许信息不完整时导出。
- Allegro Interactive BOM：当前板快照、离线二维/三维预览、BOM 与板图双向选择、焊接标记和本地进度保存。按当前库查找 STEP 或 Allegro 缓存网格，缺失模型本体留空；丝印仅显示选中器件。
- Windows 安装向导：选择 Cadence 路径、完整部署、UTF-8 失败日志、重复安装与卸载保护；修复首次打开向导过早展开应用目录的错误。

## 下载与安装

下载 `EdaKit-0.1.0-Setup.exe`，对照 `SHA256SUMS.txt` 校验。
保存工程并退出 Capture、Allegro，运行安装包，选择 Cadence SPB 根目录（例如 `D:\Cadence\SPB_17.2`），安装后重新打开 Cadence。
使用 Cadence 的同一账号安装。首次在商城设置中确认原理图、PCB 和 STEP 库路径。
卸载保留用户配置、器件库和导出文件。

## 验证与边界

- 全量回归 650 passed / 2 skipped；冻结程序 12 项自检通过。
- 在隔离假 Cadence 树验证不指定 CADENCEROOT 的初始化、安装、重复安装、卸载、配置块去重及保留用户文件。
- 原生功能主要在 Cadence 17.2 验收，其他版本尚需实测。
- iBOM 三维预览板厚默认 1.6 mm 示意，尚未覆盖完整铜走线、过孔、槽孔和全部丝印；缺失模型不补造本体。
- 安装失败保留可卸载程序及 deployment.log，不执行整份用户配置回滚；跨管理员账号安装尚未验收。
