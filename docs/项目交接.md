## 本轮属性处理

| 精确属性名 | 来源 |
| --- | --- |
| Description | CAD 符号 Description，缺失时使用 CAD 元件 description |
| PCBFootprint | 实际生成的 PCB 封装库名，与 Capture 内置 PCB Footprint 同值 |
| Manufacturer | CAD 符号 Manufacturer |
| Manufacturer_PN | CAD 符号 Manufacturer Part，保留实际厂家料号，不用内部别名替代 |

在正式 capture_lib.py 生成的 Package 中将四个 SymbolUserProp 写入 LibPart/NormalView，放在引脚之后、NormalView 结束前，符合本机 Capture 17.2 olb.xsd。Capture 放置实例继承符号属性；此前写入 PackageUserProp 的范围不会随放置继承。属性不新增图面显示项，PartValue 继续保留完整原型号。没有上游值时保留空字符串，不合成描述或料号，不增加商城网络请求。部分 CAD 源数据（如 RP2040 的 Description）本来为空。

CAPTURE_FORMAT_VERSION=4，所有生产放置/导出元件的内部名使用 _P4 修订后缀；原 _P3、_G2 电容及无后缀定义均不会被本轮新放置复用。名称仍受 31 UTF-8 字节限制，PlacePart 请求名与库名保持一致。符号几何修复和可见 Value 不变，已放置实例不自动改写。

本轮生产改动为 src/edakit/symbol/capture_lib.py、symbol/prepared.py；pipeline.py 沿用既有修订常量机制；测试覆盖生成器、缓存、流水线、导出与 HTTP 请求。网页、Tcl、配置和队列协议均沿用已确认版本。

## PCB 封装功能进度（2026-10-21）

按技术规划启动 Allegro PCB 封装候选生成。`easyeda/parse.py` 解析 PAD、TRACK、CIRCLE、ARC、SOLIDREGION 并保留画布原点；封装坐标转换为 `(canvas - origin) × 0.254 mm`，Y 不翻转。`footprint/padstack.py` 按焊盘号合并层并校验位置、旋转和孔径；`footprint/skill.py` 输出隔离目录可运行的 SKILL 候选脚本，拒绝覆盖已有 `.dra/.psm`。

当前脚本支持矩形/圆/OBLONG 标准 Padstack、引脚、直线 TRACK、CIRCLE、绝对 M/L/Z 的 SOLIDREGION 及 PLACE_BOUND。C2040 真实样例含 57 个焊盘、14 条 TRACK、5 个圆、116 个填充区域；这 116 个区域的路径均为 M/L/Z，生成脚本保留全部区域。极性标记圆暂映射到顶层丝印；DOCUMENT/BOARD_OUTLINE 和部分 SOLIDREGION 层映射仍需在 Allegro 中核实。ARC、独立孔、矩形图元、未知层和曲线路径明确报错，不静默舍弃。完整 stage 在封装脚本不支持时写 warning 并继续 Capture/STEP 准备；Capture-only 根本不生成 Allegro 脚本。

自动化验证：PCB 封装/解析/流水线定向测试 32 passed；全量测试 382 passed、1 skipped。自动测试不能视为 Allegro 验收。尚未在隔离符号编辑器中确认 `axlDBCreatePadStack`、`axlDBCreatePin`、`axlDBCreateShape` 等原生调用签名或生成的 `.pad/.dra/.psm`。下一步用隔离输出目录和独立 Allegro 17.2 符号编辑器验收 C2040 及基础两焊盘样例，核对引脚编号、尺寸、铜层、丝印/装配/PLACE_BOUND 与保存编译结果；不要对用户正在编辑的工程运行脚本。
