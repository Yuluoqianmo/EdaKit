最新正式版为 [v0.1.7](https://github.com/Yuluoqianmo/EdaKit/releases/tag/v0.1.7)，发布源码以 `v0.1.7` 标签为准。源码、程序、CLI 和安装器版本一致。后续未发布改动以 Git 工作区及提交记录为准，不应将 main 上的所有修改视为已进入此安装包。

Release 提供 EdaKit-0.1.7-Setup.exe、SHA256SUMS.txt 和 release-sha256.json。安装包已回下载核对 SHA-256；主分支和版本标签的 Windows / Linux Actions 均通过。Linux CI 只验证自动化测试，Linux 安装和 Cadence 集成未进行整体实机测试。

## 已实现功能

- Capture 器件商城：立创检索、符号与封装预览、器件放置、PCB 封装生成、STEP 下载绑定和独立库路径设置。
- 工程器件属性：原生字段、搜索排序、冻结表头、批量编辑、Excel 粘贴、草稿恢复、同步冲突检查；双击 Reference 定位原理图器件，支持当前显示顺序向下拖拽填充。
- BOM：中文 Excel 模板、元信息编辑、类型判断、按 Manufacturer_PN 匹配公司物料编码、手工增减物料及允许不完整字段导出。
- Allegro 交互式 BOM：原生入口、输出窗口及进度、离线 HTML、板图定位、焊接标记、原生位号位置和真实 3D 模型，增加手机横竖屏布局、触屏手势和选中器件聚焦。缺失模型时不生成模拟本体。
- 关于页面：版本和项目链接、检查更新、下载校验、安装交接、环境诊断与日志文件夹。Diagnostics 子菜单已移除，后台日志保留。

Capture 商城、属性和 BOM 共用工作台；关于页面独立打开。详细步骤见 [README](../README.md)、[定位与填充](器件属性定位与填充.md) 和 [关于、更新与诊断](关于更新与诊断.md)。

## 开发与文件组织

程序代码位于 src/edakit，前端源码位于 frontend。前端修改后使用 tools/build_web.py 生成 server/web 部署资源，并运行 --check 核对一致性。保持旧 CEF 的 ES5 及兼容 CSS，不应直接引入宿主不支持的浏览器接口。

使用 Python 3.13 和 requirements-build.lock；原生 Tcl 测试需要 tclsh。构建及安装步骤见 [首页](../README.md#开发与构建) 和 [安装包文档](安装包开发-20261023.md)。源码修改不会自动更新已安装的冻结程序或 Cadence 脚本。

仓库保留源码、必要样本、测试、构建脚本、文档及许可；缓存、安装包、QA 输出和本机备份不入 Git。发布附件通过 Releases 分发。用户配置、器件库和工程不作为可清理构建产物。

项目原创代码使用 [MIT License](../LICENSE)。第三方依赖和数据各自保留权利，见 [NOTICE](../NOTICE) 及 [licenses](../licenses)。项目 LICENSE 已随 v0.1.7 构建和安装包分发；v0.1.6 标签和历史附件保持不变。

按用户要求，功能修改先交实机测试，明确要求后再推送和发布；真实跨版本更新测试当前搁置。

本轮移动端操作与适用范围见 [交互式 BOM 移动端](交互式BOM移动端.md)。
