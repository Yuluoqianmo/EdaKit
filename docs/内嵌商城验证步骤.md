# 内嵌商城优化版：更新与验证

## 1. 准备

在 Capture 按两次 Esc，保存测试工程，完全退出 Capture。关闭旧商城/服务控制台。

如果没有可关闭的服务窗口，在 PowerShell 执行以下命令，只停止当前项目主 exe 的旧服务：

```powershell
Get-CimInstance Win32_Process -Filter "Name = 'edakit.exe'" |
    Where-Object { $_.ExecutablePath -eq 'E:\outputs\edakit\dist\edakit.exe' } |
    ForEach-Object { Stop-Process -Id $_.ProcessId -ErrorAction SilentlyContinue }
```

无需重新构建，也无需安装 Python 或 PNG 依赖。

## 2. 替换、自检、部署

在 PowerShell 按顺序执行，任一步报错就停止，把输出发回：

```powershell
Set-Location -LiteralPath 'E:\outputs\edakit'
Copy-Item -LiteralPath '.\dist\embedded-ui\edakit.exe' -Destination '.\dist\edakit.exe' -Force
.\dist\edakit.exe selftest
```

预期自检 10 项全部 OK，包含“PNG 内嵌预览”。如果 exe 被占用，先关闭旧服务后重试复制。

```powershell
.\dist\edakit.exe deploy --cadence-root 'D:\Cadence\SPB_17.2' --no-allegro
```

预期部署完成；本轮不配置 Allegro 环境。重新启动 Capture。

## 3. 入口与分类

打开测试工程，点击 EdaKit。预期只有 LCSC Mall、Capability Probe、Log 三项，无 Browser 项。

点击 LCSC Mall：预期在 Capture 内打开 EdaKit Mall 页签，不打开外部浏览器。先检查顶部连接状态，再逐级选择“无源器件 → 电阻器 → 贴片电阻”。预期分类显示中文、下一层按选择刷新，并出现该类搜索结果。

失败时提供整个内嵌页截图和对应分类名称；技术缩写保留是正常行为。

## 4. 固定详情

搜索 RP2040 或电阻；将每页改为 100 条。单击任一结果，然后只滚动左侧列表到靠下位置。

预期：右侧元件名称、放置按钮和封装预览保持可见，不需要滚动整页寻找。缩小 Capture 窗口再试；小窗口可以使用“大图查看”。

失败时提供整个 Capture 窗口截图，说明屏幕分辨率/系统显示缩放。

## 5. PNG 与缩放

单击 C25804，再单击 C2040，分别检查封装是否出现；切换“原理图符号”检查符号预览。

- 点击 ＋/−：比例变化、图形大小变化。
- 点击“适应窗口”：回到居中完整视图。
- 鼠标放在图形区域滚轮缩放；放大后按住左键拖动。
- 双击预览或点击“大图查看”：预览铺满内嵌页；放大并拖动检查焊盘编号。
- 按 Esc 或点击“关闭大图”：回到列表/详情，不打开外部窗口。

预期不出现 SVG 不支持提示或破图。默认密集封装编号较小，请放大查看；编号不应重叠成一片。

失败时说明是“图片不出现”“按钮无效”“滚轮无效”“拖动无效”还是“关闭失败”，并截图。

## 6. 放置回归

先用 C25804：点击“跟随光标放到原理图”，切回原理图，移动鼠标、单击落位、Esc 退出。再测试 C2040，检查引脚与编号。另提交一次，未落位就 Esc，检查没有遗留器件。

预期与上一版已验证的 PlaceNew 行为一致。此步不测试 Allegro 封装生成。
