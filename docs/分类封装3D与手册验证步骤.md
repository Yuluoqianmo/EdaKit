# 分类、封装筛选、3D 与手册：更新和验证

本版同时包含固定结果表头、紧凑“放置”按钮以及本轮新增功能。

## 1. 关闭和备份

在 Capture 按两次 Esc，保存测试工程，完全退出 Capture，关闭旧商城服务。
在 PowerShell 执行，只停止当前项目主 exe 的进程：

```powershell
Get-CimInstance Win32_Process -Filter "Name = 'edakit.exe'" |
    Where-Object { $_.ExecutablePath -eq 'E:\outputs\edakit\dist\edakit.exe' } |
    ForEach-Object { Stop-Process -Id $_.ProcessId -ErrorAction SilentlyContinue }
```

## 2. 替换和自检

按顺序执行；报错就停止，保留输出：

```powershell
Set-Location -LiteralPath 'E:\outputs\edakit'
Copy-Item '.\dist\edakit.exe' '.\dist\edakit.before-catalog-3d.exe' -Force
Copy-Item '.\dist\catalog-3d\edakit.exe' '.\dist\edakit.exe' -Force
.\dist\edakit.exe selftest
```

预期 11 项全部 OK，包含“PNG 内嵌预览”和“3D 模型预览”。不用重新构建或安装依赖。TCL 本轮未改，已有插件仍使用相同主 exe 路径，无需重新部署。

重新打开 Capture 和测试工程，从 EdaKit → LCSC Mall 进入。

## 3. 实际分类与封装

1. 展开一级分类，检查电容、电阻、连接器、二极管、电源管理、单片机等分开出现，无五金/办公/工业耗材。
2. 选择“电阻 → 贴片电阻”，等待顶部“封装”下拉框加载。预期有 0402、0603、0805 等选项，数量不是由当前每页条数决定；上游选项会随商品变化。
3. 选择 0603，检查结果封装列均为 0603；改选 0402，结果应随之改变。切换页码、每页数量，筛选应保留；改选“全部封装”恢复结果。
4. 搜索 RP2040，预期清除旧分类和封装条件；封装筛选应包含 LQFN-56(7x7)。选择该封装后应保留 RP2040，对应 C2040。
5. 选择长封装名的器件，预期列表封装列换行显示，不再省略后半段；详情中也能查看完整名称。上游没有提供封装的商品显示“商城未提供”，不猜测封装。

封装加载失败时检查服务控制台，并记录关键词/完整分类路径；不需要反复快速点击。

## 4. 3D 模型

1. 搜索并选择 C2040，等待详情后点击“3D 模型”。首次需要联网下载真实模型。
2. 预期出现 RP2040 的实体外形，不是二维焊盘图。
3. 点击左右旋转和“俯仰”，检查视角改变；按住鼠标拖动并松开，检查视角更新。
4. 点击 ＋/− 或使用滚轮，检查大小变化；点击“适应窗口”恢复完整视图。
5. 点击“大图查看”，重复旋转、缩放；按 Esc 返回列表。3D 是按需更新图片，拖动松开后刷新视角。
6. 切换“PCB 封装”“原理图符号”，检查二维显示仍正常。
7. 若其他器件没有模型，预期 3D 页签禁用；有模型但下载失败则显示失败提示，此时请记录 C 编号和日志。

## 5. 数据手册

1. 选择 C2040，确认“Datasheet 数据手册”可用。
2. 单击后，预期系统默认浏览器打开该器件的 PDF；标题/内容为 Raspberry Pi RP2040。允许打开这个文档窗口，商城本身仍保留在 Capture 内。
3. 改选 C25804，再检查手册链接和 PDF 是否对应这个电阻，不能继续打开 RP2040 的手册。同系列器件可能共用规格书，PDF 文件名不一定含当前 C 编号，应以商城关联的型号/系列判断。
4. 快速切换不同器件，检查最终显示的是当前器件的手册；缺少手册时显示“暂无数据手册”，不沿用上一器件链接。
5. 资料查询失败时显示查询失败，可换选其他器件后再选回重试。

## 6. 原有功能回归

每页 100 条，滚动左侧列表，确认表头固定、各列对齐、右侧详情保持可见。“放置”仍为紧凑按钮。
依次用 C25804 和 C2040 点击“放置”，切回原理图，确认跟随光标、单击正常落位、引脚正常，按 Esc 退出。

## 反馈格式

```text
分类：正常/异常（名称或路径）
封装：选项正常/异常；0603、0402 筛选正常/异常；长名称完整/截断
3D：显示、旋转、拖动、缩放、大图、Esc 正常/异常
手册：C2040 对应正确/错误；C25804 对应正确/错误；浏览器正常打开/未打开
原有表头与光标放置：正常/异常
```

异常时附完整 Capture 截图、C 编号、当前筛选条件与服务控制台相关输出。
