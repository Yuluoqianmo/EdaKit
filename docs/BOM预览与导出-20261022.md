# BOM 预览与导出

Capture 菜单 `EdaKit → BOM Preview` 打开独立 CEF 页面，沿用商城与属性表已验证的 `openCefDock` 生命周期。读取整个工程后生成中文 BOM，原理图器件属性只读，不执行属性同步或保存工程。

## 使用

1. 打开工程，点击“读取整个工程”。多单元符号按同层级位号合为一个物理器件，再按全部输出物料属性汇总。NC 值仍计入，不自动视作不装。
2. 主界面只显示读取、搜索、待处理筛选、匹配编码及导出。名称、制表人、日期、模板、目录和字段映射收在“导出设置”中。表头支持排序，搜索位号、型号和描述；“只看待处理”显示缺失、冲突和待分类项。分类来源仅悬停显示，问题摘要悬停可看详情。
3. 导入提供的 `.xlsx` 模板：单工作表，第一行为标题及制表信息，第二行为十列中文表头，第三行为明细样式。导出保留字体、颜色、边框、列宽及标题合并结构，重新生成全部数据及行高；不复用旧物料、旧标题、共享字符串、外部 VLOOKUP、宏或其他旧工作表内容。
4. 可导入 `.xlsx` / `.csv` 公司物料编码表，选择工作表、实际表头行、厂家型号列、编码列及可选类型列，再“确认导入并匹配”。导入可在预览后进行，导出前重新导入也会更新匹配。
5. 封装名为 `TP` 或 `testcoupf`（忽略大小写和首尾空格）识别为测试点，保留在 BOM；不要求数字位号、厂家型号或采购编码。其他类型优先级：公司编码表类型 → 指定 Capture 类型属性（默认 `Type`）→ 位号／描述规则 → 待分类。可手动修正本次 BOM 类型，不回写 Capture。
6. 选择导出文件夹即可直接导出 Excel。所有信息允许留空，缺失型号、编码未匹配、未分类、未标注位号及属性冲突均只作预览提示，不阻止导出。歧义字段保留为空，不擅自选择冲突结果；可导出后在 Excel 中补充。已移除“允许编码留空”开关。名称留空时文件名使用 BOM，单元格仍留空；日期、制表人也可为空。每次生成带时间戳的新文件，不覆盖已有输出。

7. 编码未匹配或编码表该单元格为空时，直接在“物料编码”列填写。手填编码保留前导零，进入 Excel 导出并按当前会话保存，不写回 Capture 或公司编码源表。对于无厂家型号的物料，明确手填编码后可导出；厂家型号列仍保持原值，不作推断。已有唯一匹配结果优先使用编码表；重复冲突仍会提示，导出时不自动选取冲突编码。重读同工程、重新打开或重新导入编码表可保留手填值，切换工程则清除旧工程修正。

8. 序号旁复选框控制是否导出；取消勾选的物料变灰，保留预览以便恢复，其缺失或冲突不再阻止导出。工具栏“新增物料”可填写类型、描述、位号、值、封装、数量、厂家、厂家型号和物料编码；所有字段均可留空；数量若填写，须为大于零的有效数字，留空则按空单元格导出。手动物料的位号、封装及厂家可为空。新增行通过“编辑”修改或删除。新增行和排除状态一同保存当前工程草稿；工程切换时清除，重读同工程保留。所有增减均只影响 BOM，原理图和编码源表不变。导出只保留已勾选行，重新连续编号，并显示实际导出物料项数及已填写数量之和；全部排除时不生成空清单。

9. 表头使用独立固定区域，不依赖 Capture 旧 CEF 不支持的 sticky 定位。表格纵向滚动时表头固定，横向滚动同步，窗口缩放和数据刷新后重新对齐列宽；滚动条占位也一并处理。编码表导入区的输入、下拉框及“读取列名”按钮统一为 32px 高并底部对齐，窄窗口按完整控件组换行，避免挤压或拉高。

## 字段规则

| BOM 列 | 来源 |
| --- | --- |
| 序号 | 汇总后的顺序 |
| 类型 | 自动判断或本次手动修正 |
| 描述 | `Description`，可配置原生属性名 |
| 位号 | Capture occurrence Reference |
| 值 | `Value`，可配置 |
| 封装 | `PCB Footprint`，可配置 |
| 数量 | 物理封装数，多单元去重，重复层级分别计数 |
| 厂家 | `Manufacturer`，可配置 |
| 厂家型号 | **仅 `Manufacturer_PN`**，空值提示缺失，无其他别名回填 |
| 物料编码 | 导入表按厂家型号匹配，保留编码前导零 |

型号匹配忽略首尾空格和大小写，保留内部空格及标点。同一型号重复行结果完全一致可合并；编码或类型不同则提示冲突，不选第一条、不做模糊匹配。

模板、字段映射及编码表放在 `%LOCALAPPDATA%/edakit/bom/`，公司数据不进入源码或 Git。编码表 Excel 中的公式只读取已缓存结果；公式没有缓存值时应先在 Excel 中计算保存。CSV 支持 UTF-8 和 GB18030。文件大小上限 8 MB，工作簿解压大小上限 40 MB，明细上限 100000 行。不支持旧 `.xls`、多工作表或不同表头结构的 BOM 模板。

页面保存当前会话的名称、制表人、日期、导出目录及类型修正；重新打开需点击读取，避免把历史器件表当成当前工程。修改 Capture 属性后也需重新读取。

## 验证与边界

自动回归、浏览器交互、实际模板样式及冻结程序验证的最终结果见项目交接。浏览器测试为隔离数据输入加真实 HTTP/BOM 服务，不能替代用户工程的原生 CEF 验收。实际模板验证覆盖 51 项物料、223 个器件、10 类，源文件哈希保持不变；外部 VLOOKUP 不进入输出。另用此前原生 DBO 读取的 328 个单元验证得到 325 个物理器件。

更新包含 Tcl 菜单，需保存工程并完整退出／重开 Capture，入口为 `EdaKit → BOM Preview`。本机程序、安装 Tcl 与手动 Tcl 已更新，提供的模板已设为本机默认模板，源文件未改动。冻结程序 12 项自检及 BOM HTTP 集成验证通过。本轮未提交或推送 Git。
