# 器件属性定位与填充

## 原理图定位

在 Capture 的 EdaKit → Component Properties 中读取器件后，双击 Reference 单元格或按 Enter，可跳转到原理图对应器件并缩放。多单元器件先选择单元；定位保留尚未同步的属性草稿。

定位校验工程、实例 ID 和位号，并检查返回的选中对象。缺少原生跨层级接口的 Cadence 版本仅支持当前层级定位。定位不增加后台扫描或定位后的延时轮询。

## 拖拽填充

选中可编辑单元格后，拖动右下角黑色填充柄向下复制内容。操作仅作用于当前页、筛选排序后的实际显示行，不跨页、不生成递增序列。空值、多行文字和数字字符串原样复制。

只读源单元格不显示填充柄，只读目标会跳过。同一器件的多个单元会一并更新；混合源值需先编辑成一致值。单次最多更新 2000 个实际单元格。

拖到表格边缘会自动滚动；Esc、失去焦点或离开页面取消未完成的拖拽。完成后可“撤销本次填充”，只还原仍保持填充值的草稿，不覆盖后续修改或已同步内容。

编辑和填充仅修改草稿。确认后点击“同步到 Capture”写入工程。

## 验证

用户已确认双击定位、工作台响应和拖拽填充功能正常。原生桥接使用 Tcl 回归验证，填充交互使用 Edge 浏览器测试。浏览器回归入口为 tests/test_properties_fill.py 和 tools/diag/properties_fill_qa.cjs；需要 Node、Playwright 与对应浏览器。
