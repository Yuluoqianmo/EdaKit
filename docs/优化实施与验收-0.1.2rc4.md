## 测量与边界

- 使用同一 Edge / Playwright、同一 500 行合成快照，每页实际渲染 100 行，测量 10 次。A 批保留原始行高算法的测量中间耗时约 250ms，rc4 约 41ms；样本记录见 `frontend-benchmark.json`。这是浏览器合成样本，不代表 Capture 中的实际收益。
- 480 / 720 / 1400px 宽度下验证冻结表头、横向列对齐、排序及页脚；480×400 时同步结果展开到 120px，表格维持 150px、页脚仍固定。Edge 新内核不能替代 CEF45 实机结论。
- 网络慢块、逐字节涓流、迟到响应头和超大响应使用本地 HTTP 服务测试。预算不是硬截止时间，DNS、响应头和涓流仍可能超过前端等待。
- 客户端池在异常时保守退役该客户端，正常请求复用；每个租约期间客户端仅由一个线程使用。并发请求由现有 48 槽限制，空闲池每类最多 8 个。
- 层级标识使用当前 native occurrence ID、live occurrence pointer、工程及活动页信息。未声称已验证完整层级 ID 链；如果 ID API 不可用则回退完整读取。只读探针见 `tools/diag/capture_context_probe.tcl`。
- CEF 隐藏或宿主强制终止不保证触发生命周期事件，最后约 500ms 尚未落盘的输入仍可能丢失。未配对草稿只能复制或明确丢弃，不自动重放。

## 诊断与配置

- 启动 Capture / 服务前设置 `EDAKIT_DIAG=1`，上下文分段计时写入应用数据目录的 `diag/context-timing.log`；HTTP 路由计时走现有服务日志，不记录凭证和请求正文。
- 属性页或 BOM 页 URL 添加 `perf=1` 可显示渲染计时。
- `::edakit::properties::fingerprint` 设为 `0` 恢复完整上下文读取；`::edakit::properties::fingerprintScanMs` 默认 `0`，设为 `2000` 可降低器件指针遍历频率，同页增删最迟在下次扫描反映。
- `config.json` 的 `extra.networkBudgets` 支持 `catalog` 和 `component`，默认分别为 10 / 15 秒。默认不修改 CLI 的既有重试策略。
- `tools/diag/bench_service.py` 提供 cold / hot / upstream 三种只读测量；upstream 需要 30 个不同关键词和 CID，并建议启动新服务以避免已有缓存。当前搜索本身不做服务端结果缓存，hot 模式的重复搜索仍访问上游；缓存命中测量适用于分类和商品详情。本轮未对真实商城执行这组测量，不宣称网络性能提升比例。

## 交付与回退

`E:/outputs/rc4-work/` 保存 rc3 基线和各批完整 tar 快照、SHA256 文件清单、相邻快照差异及验证日志。快照包含已跟踪和未跟踪但未忽略的文件，不包含 Git 元数据和安装包。按批次逆序回退；先备份当前状态，按清单识别新增文件再恢复，不能仅覆盖解压，也不要删除用户后续新增文件。

本轮未增加本地 elibz2 导入、onedir 打包、异步 OLB、3D 渲染或预览缓存重构。

## 实机验收项目（用户已确认通过）

1. 安装候选包后重新打开 Capture，验证商城、属性、BOM 入口和 CEF 关闭重开。
2. 在普通页和约 300 器件页切页、进出层级块、增删器件，再读取“当前页”和“当前选中器件”。运行只读上下文探针并保留结果。
3. 连续编辑属性后正常关闭并重开，检查草稿恢复；在 Capture 外部改同一属性后同步，确认冲突不会被覆盖。
4. 在 BOM 中连续用 Tab 补类型和编码，检查焦点、输入、滚动位置；导入编码表及增减物料后导出。
5. 调整停靠窗口至宽窄和极矮尺寸，展开至少 50 行同步结果，检查页脚及冻结表头。
6. 回归普通 / 多引脚器件放置、带 STEP 封装生成、Excel BOM 和 iBOM 导出。

Linux 整体运行及其他 Cadence 版本仍未实机验证。
