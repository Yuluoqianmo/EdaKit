# 参数面板显示修复与验证（2026-10-20）

## 本轮变化

针对用户截图：参数区的标签/按钮被压缩，横向与纵向滚动条挤占同一行空间；多参数器件的额外属性又藏在很浅的展开区域，不易查看。

- 常用参数固定为完整一行，显式设置字段容器宽高，关闭这一区域的横纵滚动，给标签和按钮留足高度。
- 原“更多参数”改为 **全部参数 (数量)**。点击后打开独立的筛选面板，按可用宽度分 2–4 列展示全部字段，面板只纵向滚动。长标题可换行，每个属性仍可搜索和多选。
- 字段少时面板高度随内容收缩；字段多时限制在窗口范围内，标题和底部操作固定，末尾参数可以滚动到达。打开面板不改变背后结果区与预览的位置。
- **完成选择**返回主界面，保留草稿但不自动查询；**应用并查询**提交组合条件。Esc 先关闭属性选项小面板，再按一次关闭全部参数；点击遮罩或关闭也保留选择。
- 仍按先选后查处理条件，查询接口、技术参数语义、Capture 放置与 Allegro 代码不变。
